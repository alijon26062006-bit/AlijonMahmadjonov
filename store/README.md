# RealPhone — сайт магазина

Статический сайт: HTML, CSS и обычный JavaScript, без сборки и фреймворков.
Открывается двойным кликом по `index.html` или по адресу `.../store/` на GitHub Pages.

```
store/
├── index.html          вся разметка страницы
├── css/style.css       стили (фирменные цвета — белый и синий с вывески)
├── js/products.js      товары: название, цена, категория
├── js/main.js          каталог, поиск, корзина, калькулятор насия
└── assets/
    ├── shop.jpg        фото витрины (баннер и блок «О магазине»)
    └── products/       фото товаров
```

## Как добавить фото товара

Файл кладём в `assets/products/` и называем **точно как `id` товара** из `js/products.js`:

| id в products.js        | файл                                   |
|-------------------------|----------------------------------------|
| `iphone-15-128`         | `assets/products/iphone-15-128.jpg`    |
| `airpods-pro-2`         | `assets/products/airpods-pro-2.jpg`    |

Пока файла нет — в карточке показывается серый контур телефона, сайт не ломается.
Фото лучше квадратное, товар на белом фоне, примерно 800×800.

## Как поменять товар или цену

Всё в `js/products.js`. Один товар выглядит так:

```js
{
  id: 'iphone-15-128',
  brand: 'Apple', category: 'phones',
  name: 'iPhone 15 128GB',
  specs: { ru: 'Black · 6/128 ГБ', tj: 'Black · 6/128 ГБ' },
  price: 7990,        // цена в сомони
  oldPrice: 8900,     // старая цена — рисуется зачёркнутой, считается скидка
  hit: true           // синий бейдж «Хит»
}
```

Категории: `phones`, `audio`, `watch`, `accessories`.
`oldPrice` и `hit` можно не писать.

## Что нужно заменить на свои данные

| Где | Что |
|-----|-----|
| `js/main.js`, первая строка | `BOT_USERNAME` — username бота-админки без `@` |
| `index.html`, блок `.pay` | номера карт (Алиф, Душанбе Сити, Эсхата) и имя получателя |
| `index.html` | телефон `+992 90 000 00 00` — встречается в шапке, контактах и подвале |
| `index.html`, `#contacts` | адрес магазина и координаты карты |

## Два языка

Русский и таджикский переключаются кнопками RU / TJ в шапке. Перевод хранится
прямо в разметке: `<span data-ru="Каталог" data-tj="Каталог"></span>`.
Чтобы добавить новый текст — пишем оба варианта в этих атрибутах, JS подставит нужный.
Выбранный язык запоминается в браузере.

## Как уходит заказ

1. Клиент собирает корзину и нажимает «Оформить заказ».
2. В окне видит реквизиты карт (номер копируется по клику) и сумму.
3. Кнопка «Отправить заказ боту» открывает `t.me/BOT_USERNAME?start=<корзина>`.
   Корзина зашита в ссылку кодом вида `3q1-7q2` — это номер товара в каталоге,
   буква `q` и количество. Заодно текст заказа копируется в буфер обмена.
4. Дальше бот спрашивает имя, номер, адрес и фото чека и передаёт заказ администратору.

Бот-админка делается отдельно; сайт токен бота не хранит и хранить не должен.
