# 📦 Счётчик товаров — телеграм-бот

Собираете товар по коробкам — говорите числа голосом, бот считает каждому человеку
отдельно и в конце присылает отчёт в Excel или PDF.

**Без платных ключей.** Никакого ChatGPT и никаких подписок: речь распознаётся
прямо на твоём компьютере (движок Vosk), считается обычной арифметикой.
Единственный «токен» — бесплатный ключ бота от @BotFather, без него Телеграм
вообще не даёт делать ботов.

---

## Как это выглядит в работе

```
Ты:  ➕ Человек  →  Иброхим
Ты:  ➕ Человек  →  Азиз

Ты нажал «👤 Иброхим» внизу  →  📍 Пишу: Иброхим

Ты 🎤: «семь шестьсот»
Бот:  ✅ Записал · Иброхим
      + 7 600 шт · услышал: «семь шестьсот»
      👤 У него: 7 600 шт (1 зап.)
      📦 Всего в смене: 7 600 шт (1 зап.)
      [✏️ Исправить] [🗑 Удалить]

Ты 🎤: «пять четыреста»
Бот:  ✅ Записал · Иброхим
      + 5 400 шт
      👤 У него: 13 000 шт (2 зап.)

Ты нажал «📊 Отчёт»  →  бот прислал файл:
      каждая запись по отдельности + итог по каждому + ОБЩАЯ СУММА
```

---

## Что умеет

| | |
|---|---|
| 🎤 **Голосом** | «семь шестьсот», «пять четыреста», «семь тысяч шестьсот» — всё это понимает |
| 🔢 **Только цифры** | Слова бот пропускает мимо ушей. «коробка семь шестьсот штук» → **7 600** |
| 🇺🇿 **Узбекский тоже** | «yetti ming olti yuz», «yetti olti yuz» → **7 600** |
| ➕ **Складывает сам** | У каждого свой счёт: сколько записей и сколько всего |
| ✏️ **Исправить** | Под каждой записью кнопка — сказал не то, поправил одним нажатием |
| 🗑 **Удалить / вернуть** | Удалённое не пропадает совсем, его можно вернуть кнопкой |
| ↩️ **Отменить** | Одна кнопка отменяет последнюю запись |
| 🔄 **Смены** | Новый день — новая смена, счёт с нуля, старое остаётся в истории |
| 📊 **Отчёт** | Excel и PDF: все записи по одной, итог по каждому и общая сумма в конце |
| 🔌 **Без интернета** | После установки бот работает даже без сети (нужен только Телеграм) |

### Защита от ошибок

Бот специально придирается, чтобы в отчёте не оказалось лишнего:

- **Услышал несколько чисел** — не гадает, а спрашивает кнопками, какое записать.
- **Ничего не разобрал** — так и говорит, не записывает наугад.
- **Слишком большое число** — переспрашивает («может, я ослышался?»).
- **То же число дважды за несколько секунд** — спрашивает, правда ли это ещё одна коробка.
- **Не выбран человек** — не теряет число, а спрашивает, кому его записать.
- **Имена без разницы регистра** — «Иброхим» и «иброхим» это один человек, не два.
- **Ничего не удаляется насовсем** — всё можно вернуть.

## Установка

Одна команда — она поставит всё сама, спросит токен и запустит бота:

```bash
bash setup-counter.sh
```

Что скрипт сделает:

1. Проверит Python (нужен 3.10+) и доставит недостающее.
2. Создаст `.venv` и поставит библиотеки.
3. Скачает голосовую модель (~45 МБ, один раз) — спросит, русский или узбекский.
4. Попросит токен бота у тебя и запишет его в `.env`.
5. Запустит бота.

### Где взять токен

В Телеграме открой **@BotFather** → `/newbot` → придумай имя → он пришлёт строку
вида `123456789:AAH...`. Её и вставь, когда скрипт попросит.

### Если хочется вручную

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-counter.txt

# голосовая модель
mkdir -p models
curl -L -o m.zip https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip
unzip -q m.zip && mv vosk-model-small-ru-0.22 models/vosk-ru && rm m.zip

echo 'COUNTER_BOT_TOKEN=сюда_токен_от_BotFather' >> .env
.venv/bin/python -m counter
```

Модели для других языков — на https://alphacephei.com/vosk/models
(бери те, что с пометкой *small*: они маленькие и быстрые).

## Запуск

```bash
.venv/bin/python -m counter
```

Остановить — `Ctrl+C`. Пока окно с ботом закрыто, он не отвечает.

### Чтобы работал сам, всегда

```bash
sudo tee /etc/systemd/system/schetchik.service >/dev/null <<EOF
[Unit]
Description=Счётчик товаров
After=network-online.target

[Service]
WorkingDirectory=$PWD
ExecStart=$PWD/.venv/bin/python -m counter
Restart=always
User=$USER

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl enable --now schetchik
sudo systemctl status schetchik      # посмотреть, живой ли
journalctl -u schetchik -f           # смотреть, что происходит
```

## Команды и кнопки

Всё делается кнопками внизу экрана, команды помнить не обязательно.

| Кнопка | Команда | Что делает |
|---|---|---|
| ➕ Человек | `/add Имя` | Завести того, кому считаем |
| 👥 Люди | `/people` | Список, переименовать, убрать, выбрать |
| 📋 Список | `/list` | Что уже записано в этой смене |
| 📊 Отчёт | `/report` | Прислать Excel или PDF |
| ↩️ Отменить | `/undo` | Убрать последнюю запись |
| ❓ Помощь | `/help` | Короткая инструкция |
| | `/new` | Закрыть смену и начать новую |
| | `/cancel` | Забыть, чего бот от тебя ждёт |

Имя человека внизу с галочкой ✅ — это тот, кому сейчас пишутся числа.
Нажал на другое имя — переключился.

## Отчёт

Кнопка «📊 Отчёт» предлагает четыре варианта: Excel или PDF, за текущую смену
или за всё время.

**Excel** — два листа:
- *Сводка* — по каждому человеку: сколько записей, сколько всего, какая доля, и строка **ВСЕГО**.
- *Записи* — каждое число отдельной строкой: кто, сколько, когда, как было сказано. Внизу **ВСЕГО**.

**PDF** — то же самое, только сразу готово к печати.

## Настройки (файл `.env`)

Обязательна только первая строка, остальное — по желанию.

```ini
COUNTER_BOT_TOKEN=123456789:AAH...     # токен от @BotFather

COUNTER_ALLOWED_USER_IDS=              # пусто = бот отвечает всем.
                                       # Впиши свой id (узнать у @userinfobot),
                                       # чтобы отвечал только тебе
VOSK_MODEL_PATH=models/vosk-ru         # где лежит голосовая модель
TZ=Asia/Tashkent                       # часовой пояс для времени в отчётах
COUNTER_UNIT=шт                        # как называть единицы: шт, пар, кг
COUNTER_MAX_AMOUNT=1000000             # больше этого числа — бот переспросит
COUNTER_DUPLICATE_WINDOW=8             # секунд, в которые повтор считается случайным
COUNTER_DATA_DIR=data                  # где хранить базу
```

Данные лежат в `data/counter.db` — это один файл, его можно скопировать
куда угодно, это и есть весь архив.

## Если что-то не так

**«Голосовой движок не готов»**
Не скачалась модель. Запусти `bash setup-counter.sh` ещё раз — он докачает.
Пока можно писать числа цифрами, бот всё запишет.

**Бот не слышит голосовые в группе**
У @BotFather: `/mybots` → твой бот → *Bot Settings* → *Group Privacy* → **Turn off**.
Потом убери бота из группы и добавь заново.

**Не разбирает числа**
Говори одно число за раз, коротко и без лишних слов: «семь шестьсот».
Длинные фразы бот слушает хуже.

**В PDF латиница вместо русских букв**
Не нашёлся шрифт с кириллицей. Поставь: `sudo apt install fonts-dejavu-core`.
На Excel это никак не влияет.

**Первое голосовое обрабатывается долго**
Модель грузится в память один раз при запуске. Дальше — быстро.

## Проверка установки

Если что-то не заводится, спроси у самого бота, чего ему не хватает:

```bash
.venv/bin/python -m counter.selftest
```

Он пройдётся по всем пунктам — библиотеки, токен, база, шрифт, отчёты,
разбор чисел, голосовая модель — и напишет, что именно чинить.
