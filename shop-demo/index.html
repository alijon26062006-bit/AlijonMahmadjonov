О Gemora: единая платформа для продажи цифровых продуктов

Gemora — это B2B-платформа для реселлеров, которая позволяет интернет-магазинам, маркетплейсам и предпринимателям продавать цифровые товары: подарочные карты, пополнения игр, подписки и ключи — через один API и веб-панель. Вместо интеграции с десятками поставщиков, ручной проверки наличия и самостоятельной обработки заказов Gemora объединяет более 10 000 продуктов из 1 000+ категорий в единый каталог.

Независимо от того, ведёте ли вы игровой магазин, маркетплейс подарочных карт или магазин цифровых товаров, Gemora обеспечивает мгновенную доставку, конкурентные оптовые цены и круглосуточное автоматическое выполнение заказов. Наш REST API позволяет создавать заказы программно, получать webhooks о статусе и встраивать доставку товаров прямо на ваш сайт или в приложение. Без ручной обработки и проблем с учётом остатков — подключитесь, добавьте товары и начните продавать.

Платформа поддерживает популярные категории: коды пополнения Steam, Roblox Robux, Discord Nitro, подписки Xbox и PlayStation, Spotify Premium, пополнения мобильных игр (PUBG, Genshin Impact, Mobile Legends) и тысячи подарочных карт для ритейла, игр и стриминговых сервисов. Все товары доставляются автоматически за секунды, а панель управления позволяет обрабатывать заказы, отслеживать баланс и просматривать каталог без написания кода.

Gemora создана для реселлеров, которые хотят масштабировать бизнес без роста нагрузки. Начните с бесплатного пробного периода, выберите тариф под объём продаж и развивайте бизнес цифровых товаров с одной платформой вместо множества.

api-example.js
// Public API v2 — profile & plan
const profile = await fetch(`https://reseller.gemora.com/api/v2/profile`, {
  headers: {
    'X-API-Key': 'YOUR_API_KEY', // or Authorization: Bearer
    Accept: 'application/json',
  },
}).then((r) => r.json());
// { ok: true, login, email, plan, planExpiresAt }
// Gift card order (get category_id & card_id from the catalog)
const order = await fetch(`https://reseller.gemora.com/api/v2/orders`, {
  method: 'POST',
  headers: {
    'X-API-Key': 'YOUR_API_KEY',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    category_id: 'YOUR_CATEGORY_ID',
    card_id: 'YOUR_CARD_ID',
    quantity: 1,
  }),
}).then((r) => r.json());
