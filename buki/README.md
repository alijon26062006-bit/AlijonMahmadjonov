# Буки — англисӣ бо забони модарӣ

Бесплатное приложение для изучения английского с объяснениями на **таджикском** (основной вариант) или **русском**.
Работает в браузере телефона и устанавливается на главный экран как приложение (PWA), без интернета после первого запуска.

- Методика и уровни: [METHOD.md](METHOD.md)
- Уроки: `js/data.js` — новый юнит добавляется одним объектом
- Адаптивный движок: `js/engine.js`
- Тексты интерфейса (tg / ru / en): `js/i18n.js`

## Запуск

```bash
cd buki
python3 -m http.server 8000   # открыть http://localhost:8000
node --test tests/*.test.mjs  # проверка движка и уроков
```

Для публикации подойдёт любой статический хостинг (GitHub Pages, Netlify).

> Таджикские тексты перед запуском должен проверить носитель языка.
