# AVERIX — лендинг

Статический сайт: HTML + CSS + JS. Без сборки, без npm, без зависимостей.
Шрифты лежат в репозитории, а не тянутся с чужих серверов.
Открывается двойным кликом по `index.html`.

```
index.html          разметка и весь русский текст
styles.css          токены и стили (цвета меняются только в :root)
fonts.css           подключение локальных шрифтов
app.js              замер страницы, язык, меню, форма
fonts/              Unbounded, Manrope, JetBrains Mono — woff2, кириллица + латиница
img/alijon.webp     фото (+ .jpg как запасной вариант)
favicon.svg         иконка вкладки
```

**Вес: 173 КБ по сети** (gzip). Фото грузится лениво, ниже первого экрана.
Повторный визит — около 30 КБ: шрифты кешируются на год.

## Идея дизайна

Страница выглядит как техническая спецификация самой себя: данные набраны
моноширинным, разделители — волосяные линии, всё выровнено по левому краю,
секции помечены `[01] … [04]`. Это рифмуется с тем, что студия продаёт —
собранное руками и измеренное.

Главный приём — **живой замер** под первым экраном. Вес страницы, время
загрузки и число запросов не вписаны в разметку: их измеряет браузер
посетителя через Performance API. Если браузер не отдаёт размеры, пункт
убирается, а не показывает выдуманное значение.

| | |
|---|---|
| Фон | `#0A090F` — почти чёрный с фиолетовым подтоном |
| Фиолетовый | `#A472E8` — осветлённый `#7021C1` из логотипа, 5.7:1 |
| Зелёный | `#34C97D` — осветлённый `#038D47`, знак «измерено», 9.1:1 |
| Текст | `#EDEBF5` (17:1) и `#A9A3BE` (8.3:1) |
| Заголовки | Unbounded 600 |
| Текст | Manrope 400–700 |
| Данные и метки | JetBrains Mono 400–500 |

Тема одна — тёмная, светлой версии нет намеренно.

## Два языка

Русский текст лежит прямо в разметке — поэтому без JS сайт полностью
читаем и индексируется поисковиками. Таджикский подставляется словарём
`TG` в `app.js` по ключам `data-i18n`. Выбор запоминается в браузере.

> **Таджикский перевод нужно вычитать.** Он сделан не носителем языка.
> Правится в одном месте — объект `TG` в начале `app.js`.

## Что править чаще всего

| Что | Где |
|---|---|
| Русский текст | `index.html` |
| Таджикский текст | `app.js` → объект `TG` |
| Цифры «3 года / 4 проекта / 100 %» | `index.html` → блок `.stats` |
| Цвета, отступы | `styles.css` → блок `:root` |
| Telegram для заявок | `app.js` → `TELEGRAM_USER` |
| Домен в мета-тегах | `index.html` → `canonical`, `og:*` |
| Фото | `img/alijon.webp` + `img/alijon.jpg` |

## Деплой на VPS

```bash
rsync -av --delete ./ user@SERVER:/var/www/averix/
```

```nginx
server {
  listen 80;
  server_name averix.tj www.averix.tj;
  root /var/www/averix;
  index index.html;

  gzip on;
  gzip_types text/css application/javascript image/svg+xml;

  # шрифты и картинки не меняются — кешируем надолго
  location ~* \.(woff2|webp|jpg|svg)$ {
    expires 1y;
    add_header Cache-Control "public, immutable";
  }
  location ~* \.(css|js)$ {
    expires 7d;
    add_header Cache-Control "public";
  }
  location / {
    try_files $uri $uri/ =404;
  }
}
```

```bash
ln -s /etc/nginx/sites-available/averix /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx
certbot --nginx -d averix.tj -d www.averix.tj
```

При 173 КБ на страницу 10 000 посетителей дают около 1,7 ГБ трафика —
это выдержит самый дешёвый VPS. Cloudflare перед сервером снимет и это.
