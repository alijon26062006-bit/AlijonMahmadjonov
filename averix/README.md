# AVERIX — лендинг

Статический сайт: HTML + CSS + JS. Без сборки, без npm, без зависимостей.
Шрифты лежат в репозитории, а не тянутся с чужих серверов.

> **Для просмотра нужен локальный сервер, а не двойной клик.**
> Браузер запрашивает шрифты в режиме CORS, и по протоколу `file://`
> такой запрос блокируется — страница откроется системным шрифтом.
> ```bash
> python3 -m http.server 8000    # затем http://localhost:8000
> ```

```
index.html          разметка и весь русский текст
styles.css          токены и стили (цвета меняются только в :root)
fonts.css           подключение локальных шрифтов
app.js              замер страницы, язык, меню, форма
fonts/              Geologica, Golos Text, JetBrains Mono — woff2, кириллица + латиница
img/alijon.webp     фото (+ .jpg как запасной вариант)
favicon.svg         иконка вкладки
```

**Вес: 202 КБ по сети** (gzip). Фото грузится лениво, ниже первого экрана.
Повторный визит — около 30 КБ: шрифты кешируются на год.

## Идея дизайна

Стеклянные слои поверх живого фона. Стекло видно только тогда, когда за ним
есть что размывать, поэтому фон — три медленно плывущих цветовых пятна,
а не плоский чёрный. Яркость пятен подобрана так, чтобы в самой светлой
точке фона весь текст держал норму контраста: основной 12.2:1,
вторичный 6.8:1, приглушённый 4.6:1, акценты 5.6:1 и 7.9:1.

Данные набраны моноширинным, секции помечены `[01] … [04]` — страница
читается как спецификация самой себя.

| | |
|---|---|
| Фон | `#0A090F` — почти чёрный с фиолетовым подтоном |
| Фиолетовый | `#A472E8` — осветлённый `#7021C1` из логотипа, 5.7:1 |
| Зелёный | `#34C97D` — осветлённый `#038D47`, знак «измерено», 9.1:1 |
| Текст | `#EDEBF5` (17:1) и `#A9A3BE` (8.3:1) |
| Стекло | `rgba(255,255,255,.055)` + `blur(22px) saturate(170%)` |
| Кромка | светлая сверху, тёмная снизу — как блик на стекле |
| Заголовки | Geologica 600 |
| Текст | Golos Text 400–700 |
| Данные и метки | JetBrains Mono 400–500 |

Тема одна — тёмная, светлой версии нет намеренно.

## Движение

Всё движение выключается при `prefers-reduced-motion: reduce` —
проверено, на странице не остаётся ни одной запущенной анимации.

| Что | Как |
|---|---|
| Фон | три пятна, циклы 42 / 48 / 55 с, только `transform` |
| Появление блоков | пружина с лёгким перелётом, ступенями по 80 мс |
| Цифры в первом экране | набегают от нуля за 900 мс при появлении |
| Карточки | блик идёт за курсором, подъём при наведении |
| Кнопки | сжатие до 0.96 при нажатии |
| Шапка | стекло проявляется при прокрутке |
| Переключатель языка | подложка едет за выбором, а не перекрашивается |
| Вопросы | плавное раскрытие, движение прерываемое |
| Меню на мобильных | выезд справа с пружиной |

Анимируются только `transform` и `opacity` — это работа композитора,
без пересчёта вёрстки.

## Два языка

Русский текст лежит прямо в разметке — поэтому без JS сайт полностью
читаем и индексируется поисковиками. Таджикский подставляется словарём
`TG` в `app.js` по ключам `data-i18n`. Выбор запоминается в браузере.

> **Таджикский перевод нужно вычитать.** Он сделан не носителем языка.
> Правится в одном месте — объект `TG` в начале `app.js`.

## Что править чаще всего

| Что | Где |
|---|---|
| Русский текст | `index.html` |
| Таджикский текст | `app.js` → объект `TG` |
| Цифры «3 года / 4 проекта / 100 %» | `index.html` → блок `.stats` |
| Цвета, отступы | `styles.css` → блок `:root` |
| Telegram для заявок | `app.js` → `TELEGRAM_USER` |
| Домен в мета-тегах | `index.html` → `canonical`, `og:*` |
| Фото | `img/alijon.webp` + `img/alijon.jpg` |

## Деплой на VPS

Всё нужное лежит в `deploy/`. Первичная установка — один раз:

```bash
ssh root@IP-СЕРВЕРА
curl -fsSL "https://raw.githubusercontent.com/alijon26062006-bit/AlijonMahmadjonov/claude/ui-ux-pro-max-landing-n9y2jh/averix/deploy/setup.sh" -o setup.sh
less setup.sh          # прочитать перед запуском
bash setup.sh averix.dev
```

Ветку указывать не нужно: скрипт берёт `main`, а если папки `averix/`
там ещё нет — ветку разработки. После слияния в `main` он сам
переключится на неё.

Скрипт ставит nginx, git и certbot, клонирует репозиторий
в `/var/www/averix-repo`, настраивает сайт, открывает 22/80/443
и выпускает сертификат. Запускать можно повторно — уже настроенное
он не ломает.

Сайт лежит в подпапке репозитория, поэтому корень nginx —
`/var/www/averix-repo/averix`.

Обновление после каждого push:

```bash
bash /var/www/averix-repo/averix/deploy/update.sh
```

Ветку `update.sh` берёт ту, что уже развёрнута, — помнить её название
не нужно. Скрипт делает `git reset --hard`, поэтому **править файлы
прямо на сервере нельзя** — изменения будут стёрты.

### Про домен .dev

Зона `.dev` целиком входит в список HSTS preload, поэтому браузеры
отказываются открывать её по `http` — не «без замка», а вообще.
Пока certbot не выпустит сертификат, сайт не откроется. Если установка
упала на этом шаге, дело почти всегда в A-записи: она ещё не разошлась.

### Про кеш

Имена файлов не содержат хеша, поэтому `css` и `js` отдаются
с `Cache-Control: no-cache`: иначе после обновления вернувшийся
посетитель неделю видел бы старую версию. Это не отключает кеш,
а требует проверки — при неизменном файле сервер отвечает 304
в несколько байт. Шрифты закешированы на год, картинки на 30 дней.

При 202 КБ на страницу 10 000 посетителей дают около 2 ГБ трафика —
это выдержит самый дешёвый VPS. Cloudflare перед сервером снимет и это.
