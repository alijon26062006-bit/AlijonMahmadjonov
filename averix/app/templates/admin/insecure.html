Админка требует HTTPS

Сейчас страница открыта по http.

По незащищённому соединению пароль уходит на сервер открытым текстом — его видит любой узел по пути. Поэтому вход отключён намеренно, а не сломался.

Выпустите сертификат на сервере: 

certbot --nginx -d {{ host }}

После выпуска откройте https://{{ host }}/admin — вход заработает.
