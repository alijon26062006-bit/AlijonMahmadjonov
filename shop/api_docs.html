Ключ API

Ключ вы создаёте сами, прямо в боте — без писем и заявок:

  1. Откройте бота и нажмите кнопку «🔌 API барои барномасозон».
  2. Нажмите «🔑 Калид сохтан» (создать ключ).
  3. Бот покажет ключ вида ak_live_… — сразу скопируйте его: повторно он не показывается.

Если ключ потерялся или попал к постороннему — нажмите «♻️ Калиди нав». Старый ключ перестанет работать мгновенно, а все ваши заказы и баланс останутся на месте.

Авторизация

Передавайте ключ в каждом запросе одним из двух способов:

X-API-Key: ak_live_ВАШ_КЛЮЧ
Authorization: Bearer ak_live_ВАШ_КЛЮЧ

Все запросы и ответы — в формате JSON (UTF-8). В POST-запросах укажите заголовок Content-Type: application/json.

Каждый ответ содержит поле ok: true — успех, false — ошибка с полями code и error.

Баланс и цены

  • Баланс — тот же, что в боте. Пополнение — через бота (Душанбе Сити, Alif Mobi).
  • Цены для API — специальные: они рассчитываются от закупочной цены поставщика и могут отличаться от цен в боте.
  • Цены обновляются автоматически вслед за поставщиком. Всегда берите актуальную цену из /products перед покупкой — в ответе на заказ указана точная списанная сумма.
  • Деньги списываются в момент создания заказа. Если заказ не выполнен — вся сумма автоматически возвращается на баланс.
  • Все суммы — строки с двумя знаками после точки, валюта TJS (сомони).

Проверка аккаунта

POST/checkбесплатно

Узнать ник игрока до оплаты — чтобы покупатель убедился, что ID его. Деньги не списываются.

Запрос
curl -X POST {{BASE}}/check \
  -H "X-API-Key: ak_live_ВАШ_КЛЮЧ" \
  -H "Content-Type: application/json" \
  -d '{"product": "pubg_60", "player_id": "5123456789"}'
Ответ 200 — аккаунт найден
{"ok": true, "supported": true, "valid": true, "nickname": "PlayerOne"}
Ответ 200 — неверный ID
{"ok": true, "supported": true, "valid": false, "nickname": null,
 "message": "Аккаунт не найден или ID неверный"}

Если supported = false, для этого товара проверка недоступна — покупать можно, но ник не будет известен заранее.

Повтор без двойной оплаты

Связь может оборваться ровно в момент покупки — и вы не узнаете, создан заказ или нет. Чтобы безопасно повторить запрос, передавайте заголовок:

Idempotency-Key: любая-уникальная-строка-до-100-символов
  • Тот же ключ и то же тело запроса — вернётся уже созданный заказ с пометкой "duplicate": true. Деньги второй раз не списываются.
  • Тот же ключ, но другое тело — ошибка 409 idempotency_key_reused.
  • Удобно использовать номер заказа в вашей системе: my-shop-order-1001.

Ограничения

  • До 120 запросов в минуту на один ключ.
  • До 30 заказов в минуту на один ключ.
  • Статус заказа опрашивайте не чаще раза в 5 секунд.
  • Размер тела запроса — до 32 КБ.

Примеры кода

Полный цикл: проверка ника → покупка → ожидание результата.

import time, uuid, requests

API = "{{BASE}}"
HEADERS = {"X-API-Key": "ak_live_ВАШ_КЛЮЧ"}

def buy(product: str, player_id: str) -> dict:
    # 1. Проверяем ник (необязательно, но удобно)
    check = requests.post(f"{API}/check", headers=HEADERS, timeout=30,
                          json={"product": product, "player_id": player_id}).json()
    if check.get("valid") is False:
        raise ValueError("Неверный ID игрока")

    # 2. Покупаем. Idempotency-Key защищает от двойной оплаты при повторе
    r = requests.post(f"{API}/orders", timeout=30,
                      headers={**HEADERS, "Idempotency-Key": str(uuid.uuid4())},
                      json={"product": product, "player_id": player_id})
    data = r.json()
    if not data["ok"]:
        raise RuntimeError(data["error"])
    order = data["order"]

    # 3. Ждём результат
    while order["status"] == "processing":
        time.sleep(5)
        order = requests.get(f"{API}/orders/{order['id']}", headers=HEADERS,
                             timeout=30).json()["order"]
    return order

print(buy("pubg_60", "5123456789"))

const API = "{{BASE}}";

async function call(path, options = {}) {
  const res = await fetch(API + path, {
    ...options,
    headers: { "X-API-Key": KEY, "Content-Type": "application/json", ...options.headers },
  });
  return res.json();
}

async function buy(product, playerId) {
  const created = await call("/orders", {
    method: "POST",
    headers: { "Idempotency-Key": crypto.randomUUID() },
    body: JSON.stringify({ product, player_id: playerId }),
  });
  if (!created.ok) throw new Error(created.error);

  let order = created.order;
  while (order.status === "processing") {
    await new Promise((r) => setTimeout(r, 5000));
    order = (await call(`/orders/${order.id}`)).order;
  }
  return order;
}

Безопасность

Ключ — это доступ к вашему балансу. С ним можно покупать за ваши деньги.
  • Храните ключ только на своём сервере. Не вставляйте его в код сайта, мобильного приложения или бота, который видят пользователи.
  • Не отправляйте ключ в чаты и не публикуйте на GitHub.
  • Если ключ мог утечь — в боте нажмите «♻️ Калиди нав»: старый перестанет работать сразу.
  • Подозрительные заказы? Проверьте историю и напишите в поддержку магазина.
