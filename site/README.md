# Сайт Alijon — версия для обычного хостинга

Чистый HTML + CSS + JavaScript. **Ничего собирать не нужно.**
Node.js, npm, Next.js — не требуются ни на компьютере, ни на сервере.

---

## Как выложить на SomonHost

1. Зайди в файловый менеджер хостинга (или по FTP).
2. Открой папку `public_html`.
3. Загрузи туда **всё содержимое папки `site/`**.

`index.html` должен оказаться прямо в `public_html/`, а рядом с ним папки
`js/` и `fonts/`. Всё — сайт работает.

```
public_html/
├── index.html
├── style.css
├── config.js
├── lang.js
├── fonts/          15 файлов шрифтов
└── js/
    ├── app.js
    ├── scene.js
    ├── three.module.min.js
    ├── lenis.mjs
    ├── postprocessing/
    └── shaders/
```

> Структуру папок менять нельзя — файлы находят друг друга по этим путям.

## Что менять

### `config.js` — контакты, проекты, навыки

Открываешь блокнотом, правишь, перезаливаешь **только этот файл**. Всё.

**Обязательно поменяй заглушки:**

```js
display: '+992 000 00 00 00',   // ← твой номер
href: 'tel:+992000000000',      // ← и здесь

display: '@uways',                        // ← твой Instagram
href: 'https://instagram.com/uways',      // ← и здесь
```

### `lang.js` — тексты на трёх языках

Три блока: `ru`, `tg`, `en`. Меняй **только текст в кавычках**.
Структуру трогать нельзя — у всех трёх языков должен быть одинаковый набор строк.

**Таджикский переведён не носителем языка.** Пройдись по блоку `tg` и поправь,
где звучит неестественно.

## Музыка

Автозапуск звука браузеры запрещают — обойти это невозможно, поэтому звук
включается кнопкой в шапке.

1. Создай папку `audio/` рядом с `index.html`.
2. Положи туда файл, например `ambient.mp3`.
3. В `config.js` впиши:

```js
export const audio = {
  src: 'audio/ambient.mp3',
  volume: 0.35,
};
```

Пока `src` пустой — кнопка звука не показывается.

## Форма заявки

Сейчас работает так: данные форматируются, копируются в буфер обмена и
открывается твой чат в Telegram — остаётся вставить одним движением.

Так сделано потому, что Telegram **не умеет** подставлять текст в личный чат
по ссылке. Это ограничение самого Telegram, а не сайта.

Чтобы заявки приходили в бота автоматически, нужен PHP-обработчик на хостинге.
Когда сделаем — в `config.js` поменяешь `mode: 'telegram'` на `mode: 'php'`.

## Если тормозит на слабом телефоне

В `config.js` уменьши числа:

```js
export const scene = {
  buildings: { desktop: 260, mobile: 90 },   // здания
  particles: { desktop: 2600, mobile: 900 }, // частицы
  bloomOnDesktop: true,                      // свечение
};
```

На телефонах свечение и так выключено, а частиц вдвое меньше — это сделано
специально ради стабильных кадров.

## Почему шрифты лежат рядом, а не грузятся с Google

Проверил парсером шрифтов: из популярных гарнитур **все 12 таджикских букв**
(ғ ӣ қ ӯ ҳ ҷ) есть только у **Golos Text** и **Exo 2**. У Manrope, Onest и
Unbounded их нет вообще, у Rubik — 10 из 12.

Плюс так сайт не зависит от чужого сервера и грузится быстрее.

## Технические решения

**Город — один объект.** Все здания нарисованы одним вызовом (`InstancedMesh`).
Сотни отдельных объектов просадили бы кадры.

**Окна рисует шейдер.** Ни одной картинки: сетка окон считается прямо на грани
здания, часть окон горит, у каждого своя фаза мерцания.

**Карточки наклоняются средствами CSS.** Отдельная 3D-сцена на каждую карточку
означала бы шесть контекстов WebGL и мёртвую производительность.

**Первый экран написан по-русски прямо в HTML.** Поэтому страница показывается
сразу, а язык браузера определяется уже после загрузки — без мигания.
