# ZVER TAJ — Python-бот (aiogram 3)

Пошаговый бот без Mini App. Работает через **long polling**, поэтому
домен, HTTPS, nginx и сертификаты **не нужны** — только Python и доступ
к той же базе, где живёт PHP-версия.

База общая: таблицы `z_*`. Балансы, заказы и история никуда не переезжают,
обе версии видят одни и те же данные.

---

## Установка одной командой

Ключи **не спрашиваются** — установщик берёт их из вашего `config.php`
и складывает в `.env` с правами 600. Вводить руками ничего не надо.

```bash
curl -fsSL https://raw.githubusercontent.com/alijon26062006-bit/AlijonMahmadjonov/refs/heads/claude/zver-taj-server-deploy-gom4he/zver-py/install-py.sh -o ip.sh && bash ip.sh
```

`config.php` ищется по порядку: `/var/www/zver/config.php` → рядом со
скриптом → `/root/config.php`. Если его на сервере ещё нет:

```bash
scp config.php root@IP_СЕРВЕРА:/root/
```

Установщик поставит Python, зависимости, создаст системного пользователя
`zverbot`, проверит связь с базой и поднимет systemd-сервис с автозапуском.

## Что уже работает

**Для покупателя**

| Шаг | Что происходит |
|---|---|
| `/start` | регистрация, у новичка — выбор языка |
| 🎮 Купить | список игр → пакеты → ввод игрового ID → подтверждение |
| подтверждение | атомарное списание с баланса, создание заказа, уведомление админам |
| 💰 Баланс | остаток, кнопка пополнения |
| пополнение | сумма → реквизиты из `z_reqs` → фото чека → заявка админу |
| 📦 Заказы | последние 10 заказов со статусами |
| 🌐 Язык | смена языка в любой момент |

**Для админа**

`/admin` — очередь заказов и пополнений. По каждому две кнопки:
выполнить / отклонить. При отклонении заказа деньги возвращаются
на баланс автоматически. Уведомления клиенту приходят **на его языке**.

**Языки:** таджикский, русский, английский переведены полностью.
Для `uz`, `ky`, `kk` пока показывается русский — добавить перевод просто,
скопируйте блок `RU` в `texts.py`.

## Проверка денежной логики

В комплекте `test_money.py` — прогоняет на настоящей базе то, что дороже
всего сломать:

```bash
cd /opt/zverbot && sudo -u zverbot .venv/bin/python test_money.py
```

Что проверяет: баланс не уходит в минус; десять одновременных списаний
не тратят больше, чем есть; сумма всех операций в `z_tx` сходится с
балансом; повторное нажатие «выполнен» двумя админами не срабатывает
дважды; возврат зачисляется ровно один раз.

Тест сам за собой убирает — создаёт пользователя `999000001` и удаляет
его в конце.

## Управление

```bash
systemctl status zverbot      # состояние
journalctl -u zverbot -f      # живой журнал
systemctl restart zverbot     # перезапуск
systemctl stop zverbot        # остановить
```

## Важно: один токен — один приёмник

У бот-токена может быть либо webhook, либо polling, но не оба сразу.
При старте Python-бот снимает webhook, поэтому **PHP-версия на том же
токене перестаёт получать сообщения**.

Чтобы протестировать, не трогая рабочего бота: заведите тестового бота
у @BotFather и впишите его токен в `/opt/zverbot/.env`, затем
`systemctl restart zverbot`. Вернуть PHP-версию — остановить Python-бота
и открыть `?setup=1&secret=...`, он поставит webhook обратно.

## Безопасность

- `.env` не попадает в git, права 600, владелец `zverbot`
- бот работает под системным пользователем без shell, не под root
- systemd-юнит с `ProtectSystem=strict`, `NoNewPrivileges`, `ProtectHome`
- ключи в исходном коде отсутствуют — только в `.env` на сервере
