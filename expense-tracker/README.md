# Учёт расходов сотрудников

Веб-приложение на PHP + MySQL для учёта расходов сотрудников относительно их месячной
зарплаты. Две роли: **работник** (вводит свои расходы, видит остаток/долг) и **шеф**
(видит сводку по всем работникам).

## Возможности

- Работник указывает свою месячную зарплату ($) и вносит расходы (₸ или $) с описанием и датой.
- Система автоматически считает: сколько потрачено, сколько осталось от зарплаты, или сколько
  сотрудник должен, если превысил зарплату — в долларах и в тенге по заданному курсу.
- Шеф видит таблицу всех работников за выбранный месяц и может открыть детальный список
  расходов каждого.
- Шеф добавляет аккаунты работников (открытой регистрации нет).
- Вход по логину/паролю, а также через Google (если настроено) — удобно, если забыли пароль.
- Ежемесячная рассылка на email: итог каждому работнику и общая сводка шефу.

## Установка на хостинг

1. **Создайте базу данных MySQL** в панели хостинга (обычно "Базы данных MySQL" в cPanel)
   и запомните: имя базы, пользователя, пароль, хост (чаще всего `localhost`).

2. **Импортируйте схему**: откройте phpMyAdmin для вашей базы и импортируйте файл
   `sql/schema.sql` (вкладка Import/Импорт → выбрать файл → Go/Отправить).
   Это создаст таблицы и учётную запись шефа по умолчанию:
   - Логин: `boss`
   - Пароль: `boss12345`

   **Обязательно смените этот пароль сразу после первого входа** (Настройки → Сменить пароль).

3. **Настройте подключение к базе**: откройте `config/db.php` и впишите свои данные:
   ```php
   define('DB_HOST', 'localhost');
   define('DB_NAME', 'ваша_база');
   define('DB_USER', 'ваш_пользователь');
   define('DB_PASS', 'ваш_пароль');
   ```

4. **Загрузите всю папку `expense-tracker`** на хостинг через FTP или Менеджер файлов
   (File Manager) в cPanel. Рекомендуется загрузить содержимое так, чтобы файлы
   (`index.php`, `worker/`, `boss/` и т.д.) оказались прямо в корне вашего домена или
   поддомена (например, в `public_html/`), а не во вложенной папке — ссылки в приложении
   абсолютные (`/worker/dashboard.php` и т.п.) и рассчитаны на размещение в корне сайта.

5. **Откройте сайт в браузере** — увидите страницу входа. Войдите как `boss` / `boss12345`,
   смените пароль, затем добавьте работников через «Добавить работника».

6. Каждый работник заходит под своим логином/паролем, указывает в «Настройках» свою
   месячную зарплату и вносит расходы.

## Вход через Google (необязательно)

Позволяет войти без пароля — полезно, если сотрудник его забыл.

1. Зайдите в [Google Cloud Console → Credentials](https://console.cloud.google.com/apis/credentials),
   создайте OAuth 2.0 Client ID (тип — Web application).
2. В "Authorized redirect URIs" укажите: `https://ваш-домен.com/auth/google_callback.php`
3. Впишите полученные Client ID и Client Secret в `config/google.php`, а также сам домен
   в `GOOGLE_REDIRECT_URI`.
4. Каждому работнику, который будет входить через Google, укажите его email в настройках
   профиля (работник может сам указать в «Настройках», либо шеф — при создании аккаунта).
   Вход через Google работает, только если email в Google-аккаунте совпадает с email в
   системе — новые аккаунты через Google не создаются.

Если функция не нужна — просто ничего не настраивайте, кнопка "Войти через Google" будет
показывать понятную ошибку, а обычный вход по логину/паролю продолжит работать как обычно.

## Ежемесячные email-уведомления

1-го числа каждого месяца каждый работник получает на почту итог за прошлый месяц
(зарплата/потрачено/остаток или долг), а шеф — сводку по всем.

Для этого нужна cron-задача на хостинге (в cPanel: "Cron Jobs"), которая раз в день
запускает:

```
0 5 * * * php /home/ваш_пользователь/public_html/cron/monthly_summary.php
```

(путь укажите свой; время 05:00 — можно любое). Скрипт сам проверяет, что сегодня 1-е
число и что рассылка ещё не отправлена, поэтому его безопасно запускать хоть каждый час.

Отправка идёт через встроенную функцию PHP `mail()`. Если письма не доходят — уточните
у хостинга, нужно ли включать SMTP-отправку отдельно (некоторые хостинги требуют
настройки SMTP через панель вместо `mail()`).

**Важно**: чтобы работник или шеф получали письма, у них должен быть указан email в
Настройках (или при создании аккаунта).

## Известные упрощения

- Зарплата хранится как одно текущее значение на сотруднике — если сотрудник изменит
  зарплату в настройках, новое значение будет применяться при просмотре **любого** месяца
  (в том числе прошлых), а не только будущих. Для большинства случаев (зарплата меняется
  редко) это не критично.
- Курс обмена ₸/$ — один общий, задаётся шефом в Настройках, действует сразу для всех
  расчётов (нет истории курса по месяцам).

## Структура файлов

```
config/       — настройки подключения к БД и Google OAuth (правите после загрузки)
sql/          — schema.sql для импорта в MySQL
includes/     — общая логика: авторизация, расчёты, разметка страницы
auth/         — вход через Google
worker/       — панель работника
boss/         — панель шефа
cron/         — скрипт ежемесячной рассылки
assets/       — стили
```
