# 🚚 Cargo Bot — Telegram-бот карго-доставки Китай → Таджикистан

Профессиональный Telegram-бот на **aiogram 3.x** с полноценной админ-панелью.
Все тарифы, коэффициенты, курсы валют, сборы, скидки и контент хранятся в базе
данных и редактируются из админ-панели **без изменения кода и без перезапуска бота**.

## Возможности

### Для клиентов
- 📦 Пошаговый расчёт стоимости доставки (FSM): тип доставки → категория → вес → объём
- 🔍 Отслеживание груза по трек-номеру с историей статусов
- 📝 Оформление заявки (в т.ч. в один клик после расчёта) с уведомлением менеджера
- 💰 Актуальные тарифы, 📍 адреса складов, ☎ контакты, ❓ FAQ — всё из БД

### Для администраторов (`/admin`)
- CRUD по всем справочникам: тарифы, категории, типы доставки, валюты, курсы,
  коэффициенты (объёмный вес, плотный груз), доп. услуги/скидки/наценки,
  FAQ, склады, контакты, администраторы, настройки (правила округления и др.)
- Заявки: просмотр, смена статуса с уведомлением клиента
- Треки: создание (ручное/автогенерация), смена статуса + история + уведомления
- Пользователи, история расчётов, журнал всех изменений (кто/когда/старое/новое)
- 📣 Массовая рассылка, 📤 экспорт заявок и пользователей в Excel, 📊 статистика

## Логика расчёта

```
объёмный вес   = объём (м³) × коэффициент типа доставки (кг/м³)
оплач. вес     = max(фактический вес, объёмный вес, мин. вес тарифа)
базовая цена   = цена/кг × коэффициент плотного груза × оплач. вес
               → не меньше минимальной стоимости заказа
итог           = базовая цена + сборы + наценки − скидки
               → округление по правилам из настроек (none/up/down/nearest, шаг)
               → пересчёт в TJS по актуальному курсу
```

Тариф подбирается так: сначала точный (тип доставки + категория), затем общий
(тип доставки, категория не указана). Каждый расчёт сохраняется в историю.

## Установка

```bash
cd cargo_bot
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполните BOT_TOKEN и ADMIN_IDS
python main.py
```

По умолчанию используется SQLite (файл `cargo.db`) — для MVP этого достаточно.
Для PostgreSQL укажите в `.env`:

```
DATABASE_URL=postgresql+asyncpg://cargo:password@localhost:5432/cargo
```

### Миграции (продакшен)

Для MVP таблицы создаются автоматически при старте. Для продакшена:

```bash
alembic revision --autogenerate -m "init"
alembic upgrade head
```

## Структура проекта

```
cargo_bot/
├── main.py                  # точка входа
├── alembic/                 # миграции
└── bot/
    ├── config.py            # настройки из .env (pydantic-settings)
    ├── database/            # engine, sessionmaker, сид демо-данных
    ├── models/              # SQLAlchemy 2.0: 19 таблиц
    ├── repositories/        # универсальный CRUD + спец. репозитории
    ├── services/            # калькулятор, аудит-лог, экспорт, уведомления
    ├── handlers/
    │   ├── user/            # меню, расчёт, заявки, трек, инфо-разделы
    │   └── admin/           # админ-меню, CRUD-движок, заявки, треки, рассылка
    ├── keyboards/           # reply/inline клавиатуры
    ├── states/              # FSM-состояния
    ├── filters/             # IsAdmin
    ├── middlewares/         # сессия БД, регистрация пользователей
    ├── texts/               # тексты (ru; легко добавить tj/cn)
    └── utils/               # форматирование, парсинг чисел
```

## Таблицы БД

`users`, `admins`, `orders`, `tracks`, `track_history`, `tariffs`, `categories`,
`delivery_types`, `currencies`, `exchange_rates`, `coefficients`,
`extra_services`, `faq`, `contacts`, `warehouses`, `logs`, `broadcasts`,
`settings`, `calculations`.

## Как добавить новый управляемый справочник

Достаточно описать модель и добавить её в `bot/handlers/admin/registry.py` —
универсальный CRUD-движок сам построит список, карточку, добавление,
редактирование, вкл/выкл и удаление с журналированием.

## Мультиязычность

Тексты интерфейса — в `bot/texts/ru.py`. Для таджикского/китайского создайте
`tj.py` / `cn.py` по образцу и зарегистрируйте в `bot/texts/__init__.py`
(язык пользователя хранится в поле `users.language`).
