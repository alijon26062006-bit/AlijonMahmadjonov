# 🚚 Cargo Bot на PHP — карго-доставка Китай → Таджикистан

Telegram-бот для карго-компании на **чистом PHP** (без Composer и внешних библиотек).
Все тарифы, коэффициенты, курсы валют, сборы и скидки хранятся в базе данных
и меняются из админ-панели бота — **без правки кода**.

Работает на обычном PHP-хостинге: нужен только PHP, MySQL и HTTPS.

## Возможности

### Для клиентов
- 📦 Пошаговый расчёт доставки: тип → категория → вес → объём
- 🔍 Отслеживание груза по трек-номеру с историей статусов
- 📝 Заявка (в один клик после расчёта — вес и объём подставляются)
- 💰 Тарифы, 📍 склады, ☎ контакты, ❓ FAQ — всё из базы

### Для администратора (`/admin`)
- Управление тарифами, категориями, типами доставки, валютами и курсами
- Коэффициенты объёмного веса и плотного груза
- Сборы, скидки и наценки (фиксированные, процентные, за кг)
- Правила округления итоговой суммы
- FAQ, склады, контакты, список администраторов
- Заявки и треки: просмотр, смена статуса с уведомлением клиента
- Создание трек-номеров (вручную или автогенерация)
- Пользователи, история расчётов, журнал всех изменений
- 📣 Рассылка порциями, 📤 экспорт в Excel, 📊 статистика

## Требования

| Что | Минимум |
|---|---|
| PHP | 7.4+ (проверено на 8.4) |
| Расширения | `pdo`, `pdo_mysql` (или `pdo_sqlite`), `curl`, `json`, `mbstring` |
| База | MySQL/MariaDB или SQLite |
| Домен | **обязательно HTTPS** — Telegram не отправляет webhook на `http://` |

> Если домена с HTTPS нет, а есть только IP-адрес сервера — используйте версию
> на Python (папка `cargo_bot/`): она работает через long polling, и HTTPS ей не нужен.

## Установка на хостинг (Somon Host, cPanel и аналоги)

**1. Создайте базу MySQL** в панели хостинга. Запишите: имя базы, пользователя, пароль.

**2. Загрузите файлы.** Подойдёт любая из двух схем:

- *Надёжнее:* корнем сайта (или поддомена) сделайте папку `public/`,
  а `src/`, `bin/` и `config.php` положите уровнем выше — вне доступа из интернета.
- *Проще:* залейте содержимое `public/` и папки `src/`, `bin/` вместе в `public_html`.
  Файл `.htaccess` из комплекта закроет доступ к коду и настройкам.

**3. Создайте `config.php`** — скопируйте `config.example.php` и заполните:

```php
'bot_token'      => '8788793733:AA...',        // токен от @BotFather
'admin_ids'      => [7664430907],              // ваш Telegram ID
'webhook_secret' => 'придумайте_длинную_строку', // защита webhook
'db' => [
    'dsn'  => 'mysql:host=localhost;dbname=ИМЯ_БАЗЫ;charset=utf8mb4',
    'user' => 'ПОЛЬЗОВАТЕЛЬ',
    'pass' => 'ПАРОЛЬ',
],
```

**4. Создайте таблицы** — откройте в браузере:

```
https://ваш-домен/bin/install.php?key=ВАШ_webhook_secret
```

Должно появиться «Таблицы созданы» и «Демо-данные загружены».

**5. Подключите webhook:**

```
https://ваш-домен/bin/set_webhook.php?key=ВАШ_webhook_secret&url=https://ваш-домен/index.php
```

Ответ «✅ Webhook установлен» означает, что бот запущен.

**6. Готово.** Откройте бота в Telegram: `/start` — меню клиента, `/admin` — панель управления.

> Если есть SSH — те же шаги короче: `php bin/install.php`
> и `php bin/set_webhook.php https://ваш-домен/index.php`

## Проверка работоспособности

```bash
php bin/selftest.php
```

Прогоняет 99 проверок на временной базе, не обращаясь к Telegram: расчёты,
все диалоги, админ-панель, журнал, треки, рассылку, экспорт. Полезно после
правок кода и при переносе на новый хостинг.

Проверить совместимость с вашим MySQL (укажите **пустую тестовую** базу):

```bash
SELFTEST_DSN='mysql:host=localhost;dbname=cargo_test;charset=utf8mb4' \
SELFTEST_USER=пользователь SELFTEST_PASS=пароль php bin/selftest.php
```

## Логика расчёта

```
объёмный вес  = объём (м³) × коэффициент типа доставки (кг/м³)
оплач. вес    = max(фактический вес, объёмный вес, мин. вес тарифа)
базовая цена  = цена за кг × коэффициент плотного груза × оплач. вес
              → не ниже минимальной стоимости заказа
итог          = базовая цена + сборы + наценки − скидки
              → округление по правилам из настроек
              → пересчёт в TJS по актуальному курсу
```

Тариф подбирается так: сначала точный (**тип доставки + категория**), затем общий
(**тип доставки**, категория не указана). Каждый расчёт сохраняется в историю.

Все значения читаются из базы при каждом расчёте — правки из админ-панели
применяются мгновенно, перезапускать ничего не нужно.

## Структура проекта

```
cargo_bot_php/
├── public/index.php           # webhook — точка входа
├── bin/
│   ├── install.php            # создание таблиц + демо-данные
│   ├── set_webhook.php        # регистрация webhook в Telegram
│   └── selftest.php           # 99 проверок без обращения к Telegram
├── config.example.php         # шаблон настроек
└── src/
    ├── Config.php             # настройки
    ├── Database.php           # PDO: MySQL и SQLite
    ├── Schema.php             # схема 20 таблиц
    ├── Seeder.php             # демо-данные
    ├── Bot.php                # контейнер зависимостей и контекст
    ├── Texts.php              # тексты интерфейса (ru; можно добавить tj/cn)
    ├── Telegram/              # Api (cURL), Keyboard
    ├── Repository/            # универсальный CRUD, настройки, юзеры, состояния
    ├── Service/               # Calculator, Audit, Notify, Export
    ├── Handler/
    │   ├── Router.php         # разбор апдейтов
    │   ├── User/              # старт, расчёт, заявка, трек, инфо-разделы
    │   └── Admin/             # меню, CRUD-движок, заявки, треки, рассылка
    └── Util/Format.php        # форматирование и разбор чисел
```

## Таблицы базы

`users`, `admins`, `orders`, `tracks`, `track_history`, `tariffs`, `categories`,
`delivery_types`, `currencies`, `exchange_rates`, `coefficients`, `extra_services`,
`faq`, `contacts`, `warehouses`, `logs`, `broadcasts`, `settings`, `calculations`,
`states` (пошаговые диалоги — PHP не помнит контекст между запросами).

## Журнал изменений

Каждая правка тарифа, курса, коэффициента или статуса пишется в таблицу `logs`:
ID администратора, дата и время, старое значение, новое значение.
Смотреть можно прямо в боте: `/admin` → 📜 Журнал изменений.

## Как добавить новый управляемый справочник

1. Добавьте таблицу в `src/Schema.php`.
2. Опишите её в `src/Handler/Admin/Registry.php` (название, поля, порядок).
3. Добавьте кнопку в `AdminHandler::menuKeyboard()`.

Список, карточку, добавление, редактирование, вкл/выкл, удаление и журналирование
универсальный движок построит сам — писать обработчики не нужно.

## Мультиязычность

Тексты — в `src/Texts.php`, массив `$lex`. Чтобы добавить таджикский или китайский,
допишите массив `'tj' => [...]` и укажите язык в поле `users.language`.
Контент (тарифы, FAQ, склады, контакты) редактируется через админ-панель.

## Безопасность

- Webhook проверяет секретный заголовок от Telegram — чужие запросы отсекаются (403).
- `install.php` и `set_webhook.php` через браузер требуют тот же секрет.
- Все SQL-запросы параметризованы (PDO prepared statements).
- Пользовательский ввод экранируется перед выводом в Telegram.
- `.htaccess` закрывает доступ к `config.php`, базе SQLite, логам и папке `src/`.

## Обе версии бота

В репозитории лежат две реализации с одинаковой логикой и структурой базы:

| | `cargo_bot/` (Python) | `cargo_bot_php/` (PHP) |
|---|---|---|
| Технология | aiogram 3.x, long polling | чистый PHP, webhook |
| Где работает | VPS с root-доступом | любой PHP-хостинг |
| Нужен HTTPS | нет | **да** |
| Запуск | служба systemd 24/7 | по запросу от Telegram |
