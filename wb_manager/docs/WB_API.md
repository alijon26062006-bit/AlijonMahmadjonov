# WB API — подтверждённые сведения

Сюда попадает только то, что взято из документации dev.wildberries.ru (присылает Алижон).
Всё остальное лежит в PLAN.md §6 со статусом «сверить».

## Общее

- Авторизация: заголовок с токеном (`HeaderApiKey`, в документации это заголовок `Authorization`).
- Формат ошибки (Контент):
  ```json
  {"data": null, "error": true, "errorText": "...", "additionalErrors": "..."}
  ```
- Коды ответов: 200, 400, 401, 403, 429.

## Категория «Контент» (токен категории Контент)

| Контур | Хост |
|---|---|
| Prod | `https://content-api.wildberries.ru` |
| Sandbox | `https://content-api-sandbox.wildberries.ru` |

**Лимиты** (на аккаунт продавца, общие для всех методов категории Контент):

| Период | Лимит | Интервал | Всплеск |
|---|---|---|---|
| 1 мин | 100 запросов | 600 мс | 5 запросов |

- Исключения со своими лимитами: создание, редактирование и восстановление карточек, рекомендации.
  В v1 мы их не используем.
- Sandbox: **не более 1 запроса в секунду суммарно** на все методы Контента.

**Подтверждённые методы:**

| Метод | Путь | Нужен в v1 | Примечание |
|---|---|---|---|
| GET | `/content/v2/object/parent/all` | возможно (названия категорий) | query `locale=ru\|en\|zh`, в sandbox не используется |

**Ждут текста документации:**

- список карточек (`/content/v2/get/cards/list`?) — проверка 9;
- карточки с ошибками (`/content/v2/cards/error/list`?) — проверка 9;
- характеристики предмета (`/content/v2/object/charcs/{subjectId}`?) — чтобы отличать обязательные пустые характеристики от необязательных.
