# База знаний Donatix для бота поддержки
# Файл можно править без программиста: бот читает его при каждом ответе.
# Быстрые правки без файла — админ пишет боту поддержки: /learn правило

## Что такое Donatix
- Оптовый сервис цифровых товаров для игр: алмазы Free Fire, UC PUBG Mobile, Telegram Stars и Premium, пополнение Steam, подарки Steam, подарочные карты, ключи игр и другие игры.
- Клиенты — магазины, перепродавцы, владельцы ботов и сайтов. Покупают с баланса: в личном кабинете, через API или через свой Telegram-бот из конструктора.
- Заказы выполняются автоматически, 24/7, обычно за секунды.

## Регистрация и вход
- Регистрация на сайте: /register. Можно войти через Google.
- Новый аккаунт активируется сразу — можно пополнять баланс и покупать.
- Личный кабинет: /panel.

## Баланс и пополнение
- Баланс хранится в долларах ($). В кабинете можно показать сумму в сомони.
- Пополнить: кабинет → «Пополнить баланс» (/panel/balance) → способ → сумма → перевод по реквизитам → ОБЯЗАТЕЛЬНО прикрепить чек (фото или PDF).
- Без чека перевод не зачисляют. С чеком обычно проверяют до 1 часа; о зачислении приходит уведомление в 🔔 на сайте.
- Криптовалюта (USDT и др., если включена) зачисляется автоматически за 1–3 минуты, чек не нужен, но сумма и сеть должны совпадать ТОЧНО.
- Заявку на пополнение, пока она на проверке, можно отменить в кабинете.
- Статусы заявки: «на проверке», «зачислено», «отклонено» (с причиной), «отменено».
- Реквизиты называть в чате нельзя — только «смотрите в кабинете, раздел Пополнить баланс».

## Покупка
- Кабинет → каталог → игра → пакет → указать получателя → оплата с баланса.
- Получатель: ID игрока (Free Fire, PUBG и т. п.; иногда ещё сервер/зона), @username для Telegram Stars и Premium, логин Steam для пополнения Steam.
- Коды подарочных карт и ключи игр показываются на странице заказа в кабинете (/panel/orders/номер).
- Номер заказа выглядит так: dx-…; он в разделе «Заказы».

## Статусы заказа
- «в обработке» — до 10 минут нормально; дольше 30 минут — передать админу.
- «выполнен» — товар отправлен. Если не видно в игре: проверить ID получателя, перезайти в игру.
- «не выполнен» — деньги УЖЕ вернулись на баланс автоматически. Можно оформить заново (проверив ID) или выбрать другой пакет.
- Ошибка клиента (неверный ID, не тот регион) — по правилам сервиса не компенсируется, если товар уже отправлен на указанный ID.

## Реферальная программа («Пригласить друзей»)
- Кабинет → «Пригласить друзей» (/panel/referrals): там личная ссылка.
- Друг регистрируется по ссылке — с каждого его выполненного заказа приглашающему начисляется бонус на баланс (процент от прибыли сервиса), навсегда. Процент указан на странице.

## Свой Telegram-бот (конструктор)
- Можно открыть свой бот-магазин без программиста. Нужно минимальное число выполненных заказов на сайте (бот проверит функцией my_bots_status).
- Как: @BotFather → /newbot → получить токен → прислать токен в этот чат (подключу сам) или вставить в кабинете «Мой Telegram-бот». Потом в своём боте /start, затем /panel — игры, цены, реквизиты.
- Если в боте долго нет продаж — бот трижды предупреждает и отключается. Включить обратно может только администратор.

## API для партнёров
- Ключ API создаётся в кабинете. Документация — на сайте в разделе «Документация API» (/docs).
- Через API можно получить каталог, баланс, создать и проверить заказ, пополнить баланс с чеком. Повторный запрос с тем же ключом идемпотентности не создаёт второй заказ.
- Есть вебхук: сайт сам сообщит о смене статуса заказа.

## Поддержка в Telegram
- Чтобы бот видел заказы и баланс: прислать сюда email от аккаунта → код из 6 цифр придёт на сайт в 🔔 Уведомления → нажать «Копировать» и прислать код сюда. Или в кабинете «Поддержка в Telegram» → кнопка «Открыть бота».
- /forget — бот забудет, что помнил о клиенте. /logout — отвязать аккаунт.
- Живой оператор — кнопка «👤 Оператор»; ответ приходит в этот же чат.

## Прочее

- Правила сервиса: /terms.
