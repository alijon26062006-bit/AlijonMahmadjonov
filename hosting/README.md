# Averix: продажа VPS и доменов

Готовый сайт и личный кабинет хостинга. Вы подключаете ключи поставщиков — **Hetzner** (серверы и DNS) и **ResellerClub** (домены) — и продаёте.

**Клиент сам:**
- выбирает тариф на сайте и заказывает сервер (локация, ОС, свой root‑пароль);
- включает, выключает, перезагружает и переустанавливает сервер;
- **меняет root‑пароль** на свой или генерирует новый;
- смотрит **графики**: процессор, память, сеть, диск, топ процессов;
- **регистрирует домены** или подключает свои и **управляет DNS** и неймсерверами;
- пополняет баланс переводом и отправляет заявку. Серверы продлеваются помесячно, домены раз в год.

**Вы (админ):**
- видите чек‑лист «Готовность к продажам»;
- подтверждаете платежи;
- меняете цены и тарифы без программиста;
- подтверждаете клиентов (защита от спамеров);
- видите выручку и журнал действий;
- получаете уведомления в Telegram.

## Запуск за 15 минут

**Что понадобится:**
1. **Сервер для панели** — любой VPS с Ubuntu 22.04/24.04, например самый дешёвый у Hetzner.
2. **Домен для панели**, например `my.example.com`. Его DNS‑запись A должна указывать на IP этого сервера.
3. **Токен Hetzner Cloud:** Hetzner Console → проект → Security → API tokens → Generate, права **Read & Write**.
4. **Аккаунт реселлера ResellerClub:**
   - Reseller ID и API key — в разделе Settings → API;
   - **там же добавьте IP вашего сервера в список разрешённых**;
   - создайте одного Customer — на него будут регистрироваться домены;
   - пополните счёт реселлера: регистрация домена списывается с него.

**Установка на сервере — одна команда** (по SSH, от root или через sudo):
```bash
curl -fsSL https://raw.githubusercontent.com/alijon26062006-bit/AlijonMahmadjonov/refs/heads/claude/sharp-dijkstra-2jef38/hosting/deploy/get.sh | sudo bash
```
Скрипт скачает панель и спросит:
- токен Hetzner (сразу проверит его);
- домен и ваш email;
- ключи ResellerClub;
- способы оплаты.

Потом сам настроит автозапуск, nginx, HTTPS (Let's Encrypt) и ежедневную копию базы. Повторный запуск той же команды обновляет панель до последней версии.

**После установки:**
1. Откройте `https://ваш-домен` и зарегистрируйтесь с email администратора.
2. **Админка → Готовность** — доведите обязательные пункты до зелёного.
3. **Админка → Цены** — проверьте цены тарифов и доменных зон. Цена должна быть выше закупочной.
4. **Проверьте покупку домена в тестовом режиме.**
   - Пока `RESELLERCLUB_TEST=true`, регистрация идёт на тестовом сервере ResellerClub, деньги не списываются.
   - Купите тестовый домен.
   - Убедитесь, что он появился в тестовой панели ResellerClub.
   - Затем поставьте `RESELLERCLUB_TEST=false` и перезапустите панель: `systemctl restart averix`.
5. Закажите себе один сервер и проверьте:
   - смену root‑пароля;
   - графики;
   - DNS.

Все настройки лежат в `/opt/averix/.env`, пояснения к каждой — в `.env.example`.

## Как это устроено

| Что | Откуда берётся |
|---|---|
| Создание, питание, переустановка, удаление серверов | Hetzner Cloud API |
| CPU, сеть, диск | Hetzner Cloud API (`/servers/{id}/metrics`) |
| Память, место на диске, процессы | Агент `agent/averix_agent.py`. Ставится на сервер автоматически и раз в 30 с отправляет данные на `PUBLIC_URL` |
| Свой root‑пароль | Hetzner сбрасывает пароль на временный, панель заходит по SSH и ставит пароль клиента через `chpasswd`. Пароль не хранится |
| DNS‑зоны и записи | Hetzner Cloud API (`/zones`), тот же токен |
| Проверка, регистрация, продление доменов, неймсерверы | ResellerClub HTTP API. Владельцем домена указывается клиент по данным из его профиля |
| Оплата | Клиент переводит деньги на ваши реквизиты и отправляет заявку, вы подтверждаете в админке. Онлайн‑эквайринг подключается отдельно, когда выберете платёжную систему |
| Письма клиентам | SMTP: создание сервера, пополнение, напоминания за 3 дня (сервер) и 14 дней (домен), приостановка |
| Уведомления вам | Telegram‑бот: новые клиенты, заказы, заявки на оплату, ошибки поставщиков |
| Оферта, политика, правила | `/legal/offer`, `/legal/privacy`, `/legal/rules`. Реквизиты подставляются из `.env` |

## Защита бизнеса

- **Лимит для новых клиентов.** Новый клиент может держать только `NEW_USER_SERVER_LIMIT` серверов, пока вы не подтвердите его в Админке → Клиенты. Если с вашего сервера пойдёт спам или атака, Hetzner может заблокировать **весь** аккаунт.
- **Неуплата.** Сервер выключается через `GRACE_DAYS` дней после окончания оплаты и включается сам после пополнения.
- **Ошибки поставщиков.** Если Hetzner или регистратор вернул ошибку, деньги сразу возвращаются клиенту на баланс, а вам приходит уведомление.
- **Безопасность кабинета.**
  - Пароли хранятся в виде хэша scrypt.
  - Есть защита от CSRF и ограничение числа попыток входа.
  - Опасные действия (root‑пароль, переустановка, удаление) требуют пароль от кабинета.
  - Все действия пишутся в журнал.

## Что проверить самим перед запуском

- **API Hetzner** сверен с официальной спецификацией OpenAPI (docs.hetzner.cloud) и документацией по DNS‑записям: создание серверов, действия, сброс пароля, метрики, зоны и записи, цены, ошибки.
- **API ResellerClub.** Их документация закрыта защитой от ботов и не открылась для проверки. Интеграция написана по их HTTP API (LogicBoxes) и проверена тестами на подставных ответах, с настоящим аккаунтом её не проверяли. Обязательно сделайте шаг 4 из инструкции.
- **Ограничение Hetzner.** С июня 2026 Hetzner ограничивает создание серверов для новых клиентов. Если заказ возвращает «тариф недоступен», напишите в их поддержку.
- **Документы.** Оферту, политику и правила проверьте у юриста страны, где зарегистрирована компания.
- **Перепродажа.** Уточните у Hetzner и ResellerClub, разрешена ли перепродажа в вашей схеме.
- **Таджикский перевод сайта.** Его должен проверить носитель языка.

## Разработка

```bash
cd hosting
python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
cp .env.example .env        # для демо: VPS_PROVIDER=demo, DNS_PROVIDER=demo, REGISTRAR=demo, DEMO_PAYMENTS=true
.venv/bin/python run.py     # http://127.0.0.1:8000
.venv/bin/python -m pytest  # тесты
```

В демо‑режиме серверы, графики, DNS и домены симулируются, поэтому сайт можно показывать без ключей.
