# Bot Factory

Telegram-бот, который делает других Telegram-ботов.

Человек присылает ключ своего бота, полученный у @BotFather, описывает словами,
что бот должен уметь, и получает работающего бота. Дальше правит его обычными
сообщениями: «убери кнопку Доставка», «сделай приветствие короче», «добавь раздел
с ценами». Ни одной строчки кода человек не пишет.

## Кто за что платит

По умолчанию (`REQUIRE_OWN_KEY=1`) каждый человек приносит свой собственный ключ
ИИ — OpenAI или Anthropic. Фабрика хранит его зашифрованным и использует только
для ботов этого человека. Владелец фабрики за чужих ботов не платит ничего.

Ключ спрашивается один раз, при создании первого бота, и дальше работает для
всех ботов этого человека. Управление ключами — команда `/keys`.

Если хотите платить за пользователей сами, поставьте в `.env` строку
`REQUIRE_OWN_KEY=0` и впишите свой `ANTHROPIC_API_KEY`. Тогда начнёт работать
месячный лимит `AI_MONTHLY_LIMIT` на каждого бота.

## Что уже работает

- Приём и проверка чужого токена, шифрование его в базе
- Сборка бота по описанию через Claude или ChatGPT — на выбор, по ключу владельца
- Запуск созданных ботов внутри того же процесса, без отдельных серверов
- Команды, кнопки нижнего меню, кнопки под сообщениями, ссылки
- Ответы на ключевые слова
- Свободное общение с характером, заданным в описании
- Генерация картинок по команде `/image` (нужен ключ OpenAI — Claude не рисует)
- Правка бота словами, история версий и откат на предыдущую версию
- Список ботов, запуск, остановка, удаление
- Восстановление работавших ботов после перезапуска фабрики
- Команда `/stats` для администраторов из `ADMIN_IDS`: люди, боты, ответы ИИ за месяц

## Установка одной командой

На сервере:

```bash
cd ~/AlijonMahmadjonov && git pull && bash telegram-bot-factory/install.sh
```

Скрипт сам проверит Python, поставит зависимости, создаст `.env`, сгенерирует
ключ шифрования, спросит токен бота и ключ Anthropic, проверит токен в Telegram,
настроит автозапуск через systemd и запустит фабрику. Ввод секретов на экране не показывается.

Запускать скрипт можно сколько угодно раз — он доделывает то, чего не хватает,
и ничего не ломает. Обновление после изменений в репозитории — та же команда.

Если токен перестал работать (например, его сбросили командой `/revoke` в
@BotFather), скрипт скажет об этом и предложит ввести новый прямо на месте.
Чтобы заново ввести и токен, и ключ Anthropic:

```bash
bash telegram-bot-factory/install.sh --reset
```

Если что-то нужно поправить руками, всё лежит в файле `.env` рядом со скриптом.
Ключ шифрования менять нельзя: после смены сохранённые токены перестанут
расшифровываться и всех ботов придётся добавлять заново.

## Установка вручную

Нужен Python 3.11 или новее.

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
```

Сгенерировать ключ шифрования и вписать его в `.env`:

```bash
.venv/bin/python -m botfactory.crypto
```

Заполнить в `.env` три обязательных поля: `MOTHER_BOT_TOKEN` (токен главного бота
от @BotFather), `ANTHROPIC_API_KEY` (ключ с platform.claude.com) и `FERNET_KEY`.
Остальные поля можно оставить как есть, что они значат — написано в `.env.example`.

Запуск:

```bash
.venv/bin/python -m botfactory
```

В Telegram открыть своего главного бота и отправить `/start`.

## Автозапуск вручную

Это делает `install.sh`. Если нужно настроить самому:

Файл `/etc/systemd/system/botfactory.service`:

```ini
[Unit]
Description=Bot Factory
After=network-online.target

[Service]
Type=simple
User=ВАШ_ПОЛЬЗОВАТЕЛЬ
WorkingDirectory=/путь/до/telegram-bot-factory
ExecStart=/путь/до/telegram-bot-factory/.venv/bin/python -m botfactory
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Включить:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now botfactory
sudo systemctl status botfactory
journalctl -u botfactory -f
```

| `botfactory/crypto.py` | шифрование чужих токенов |
| `botfactory/storage.py` | база данных: боты, версии, лимиты |
| `botfactory/spec.py` | структура бота, её проверка и приведение в порядок |
| `botfactory/providers.py` | поставщики ИИ: Anthropic и OpenAI |
| `botfactory/generator.py` | чей ключ для чего берётся; промты сборки и правки |

| `botfactory/texts.py` | все тексты интерфейса, здесь же меняется язык |

| `install.sh` | установка и запуск одной командой |

## Как устроено внутри

Фабрика — один процесс. Внутри него живёт главный бот и все созданные боты:
у каждого свой токен и своё подключение к Telegram, но код исполняется общий.

Поведение созданного бота описано структурой данных, которую сгенерировал Claude.
Движок читает эту структуру и по ней отвечает. Правка бота — это новая структура,
записанная в базу; работающему боту она подставляется на лету, без остановки.

Сообщение разбирается по порядку: команда, потом кнопка меню, потом ключевые слова,
и только если ничего не подошло — вопрос уходит в Claude. Если свободное общение
выключено или месячный лимит исчерпан, бот отвечает заготовленной фразой.

## Что не сделано

- Приём заявок от клиентов и уведомления владельцу
- База знаний: прайс или документ, по которому отвечает бот
- Статистика и разбор вопросов, на которые бот не смог ответить
- Тестовый режим до публикации
- Генерация настоящего кода в изолированных контейнерах
- Мини-приложения внутри Telegram
- Тарифы и оплата
- Работа через webhook вместо long polling

## Безопасность

Чужие токены ботов и ключи ИИ хранятся зашифрованными, ключ шифрования лежит
в `.env` и в репозиторий не попадает. Сообщение с токеном удаляется из переписки сразу после
проверки. Файл `.env` и папка `data/` добавлены в `.gitignore` — не убирайте их
оттуда.
