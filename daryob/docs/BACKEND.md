# Сервер DARYOB

Сервер работает на Supabase: проект `daryob` (`thmptlegknxlbxmmkyrl`), регион Франкфурт.
Адрес и публичный ключ записаны в `lib/app/configuration/app_config.dart`. Публичный ключ
не секрет: что может прочитать или изменить пользователь, решают правила в базе.

Обновлено: 2026-11-22.

## Режимы сборки

| Сборка | Данные |
|---|---|
| Release (`flutter build apk`) | настоящий сервер |
| Debug, тесты | локальные демо-данные |
| `--dart-define=DARYOB_ENV=development` | локальные демо-данные в любой сборке |
| `--dart-define=DARYOB_ENV=production` | настоящий сервер в любой сборке |

## Что хранится на сервере

| Таблица | Что в ней | Кто видит и меняет |
|---|---|---|
| `profiles` | имя, город, тип аккаунта, отметки «номер подтверждён» и «заблокирован» | видят все; имя и город меняет владелец; отметки — только платформа |
| `profile_private` | номер телефона | только владелец |
| `listings` | объявления | активные видят все; свои — владелец в любом статусе |
| `listing_private` | номер продавца, если он скрыт от покупателей | только владелец |
| `favorites` | избранное | только владелец |
| `conversations`, `messages` | чаты | только два участника |
| `notifications` | сообщения платформы пользователю | только адресат; создаёт платформа |
| `reports` | жалобы | отправить может любой; читает платформа |
| `business_profiles` | профиль компании | видят все; меняет владелец |
| хранилище `listing-photos` | фото объявлений, до 6 МБ, JPEG/PNG/WebP | читать могут все; загружать — только в свою папку |

Поля, которые пользователь изменить не может, даже подделав запрос (их защищает триггер
`listings_guard`): владелец объявления, платное продвижение, счётчик просмотров, причина
отклонения и статус «отклонено». Лимит — 50 новых объявлений в сутки на аккаунт.

## Вход по коду через Telegram

1. Человек вводит номер. Функция `phone-send-code` отправляет 6-значный код в его Telegram
   через Telegram Gateway. Токен лежит в секретах Supabase (`TELEGRAM_GATEWAY_TOKEN`), в коде его нет.
2. Человек вводит код. Функция `phone-verify-code` проверяет его в Telegram и находит аккаунт:
   - номер уже подтверждён на каком-то аккаунте — вход в этот аккаунт (так аккаунт
     возвращается на новом телефоне);
   - иначе, если человек уже вошёл без подтверждения, номер привязывается к этому аккаунту;
   - иначе создаётся новый аккаунт.
3. Функция выдаёт одноразовый токен входа, приложение по нему получает сессию.

Ограничения: один код на номер в минуту, не больше 5 в час на номер и 30 в час с одного IP;
5 попыток ввода на код; код живёт 5 минут. Каждый отправленный код платный (тариф Telegram Gateway).

**Если Telegram не может доставить код** (у номера нет Telegram, шлюз недоступен), человек
всё равно входит: аккаунт привязывается к телефону, номер сохраняется без подтверждения.
По неподтверждённому номеру аккаунт не ищется — иначе любой мог бы войти в чужой аккаунт,
набрав чужой номер.

## Функции сервера

| Функция | Что делает |
|---|---|
| `phone-send-code`, `phone-verify-code` | вход по коду через Telegram |
| `device-signup` | создаёт аккаунт устройства (если код не доставлен) |
| `delete-account` | удаляет аккаунт, его объявления, чаты и фото |
| `search_listings` | поиск с фильтрами каталога и ранжированием (VIP выше, затем новые) |
| `category_counts` | число активных объявлений по категориям |
| `open_conversation` | открывает чат покупателя с продавцом по объявлению |
| `mark_conversation_read`, `set_conversation_blocked`, `hide_conversation` | прочитано, блокировка, скрытие чата |
| `seller_summary` | карточка продавца |
| `listing_viewed` | счётчик просмотров (в приложении пока не вызывается) |

Чат работает в реальном времени через каналы Supabase Realtime.

## Проверка на живом сервере

```
DARYOB_LIVE=1 flutter test test/live/server_live_test.dart
```

Тест создаёт два временных аккаунта и проверяет: вход, публикацию с фото и скрытым номером,
поиск с фильтрами, запрет на чужие объявления, избранное, чат с доставкой в реальном времени,
блокировку, правку, продажу и удаление. В конце аккаунты удаляются.

## Чего на сервере ещё нет

- SMS для номеров без Telegram.
- Push-уведомления при закрытом приложении: нужен проект Firebase. Пока уведомления о
  новых сообщениях показывает само приложение, когда оно открыто или свёрнуто.
- Оплата и включение платного продвижения.
- Модерация: объявления публикуются сразу; жалобы копятся в `reports` до появления админ-панели.
- SQL-миграции и код функций пока лежат только в Supabase, в репозиторий не выгружены.
