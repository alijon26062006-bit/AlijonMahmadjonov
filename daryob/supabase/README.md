# Сервер DARYOB (Supabase)

- `migrations/` — изменения базы. Применяются по порядку.
- `functions/` — серверные функции (Deno). `_shared/` копируется в каждую функцию при развёртывании.
- `seed/places_*.sql` — населённые пункты Таджикистана: 2 838 записей (города, посёлки,
  кишлаки, районы) из GeoNames, лицензия CC BY 4.0 (https://www.geonames.org).

Секреты функций (Supabase → Edge Functions → Secrets), в репозитории их нет:

| Имя | Для чего |
|---|---|
| `TELEGRAM_GATEWAY_TOKEN` | коды входа в Telegram |
| `OPENAI_API_KEY` | AI-модерация объявлений и чатов |
| `OPENAI_MODERATION_MODEL` | необязательно, по умолчанию `gpt-5-mini` |

Первый администратор вводит одноразовый код в приложении (Настройки → Код администратора).
В миграции хранится только хеш кода.
