# EasySIM — интернет-магазин eSIM (PHP, для Somonhost)

Полноценный магазин на чистом PHP + MySQL — без Node.js, подходит для обычного
shared-хостинга вроде Somonhost (PHP + MySQL через cPanel/ISPmanager).

## Возможности

- Каталог направлений и тарифов eSIM (мок-данные «из коробки»; при наличии
  ключей Airalo — реальный каталог и реальная выдача eSIM).
- Корзина на сессиях.
- Оформление заказа: email + телефон → SMS-код подтверждения через Zadarma →
  инструкции по оплате переводом → загрузка скриншота чека.
- Страница статуса заказа для клиента (QR-код / ICCID после выдачи).
- Админ-панель (`/admin`): список заказов, просмотр чека, подтверждение
  (выдаёт eSIM через Airalo) или отклонение оплаты.
- Виджет поддержки Zadarma WebRTC (опционально).

**Демо-режим:** пока ключи Zadarma/Airalo не заданы, сайт полностью работает —
код из SMS показывается прямо на странице, а вместо реального eSIM выдаётся
тестовый (это явно помечено и клиенту, и админу).

## Быстрый локальный запуск (без MySQL)

```bash
cd esim-store
php -S localhost:8000
```

Откройте http://localhost:8000 — база данных (SQLite) создастся автоматически
в `data/esim.sqlite`, ключи не нужны.

## Деплой на Somonhost

1. Загрузите содержимое `esim-store/` в `public_html` (или в подпапку) через
   FTP/файловый менеджер cPanel.
2. В панели хостинга создайте базу MySQL и пользователя с полным доступом к
   ней, запишите: хост (обычно `localhost`), имя базы, логин, пароль.
3. Скопируйте `config.local.example.php` в `config.local.php` (в той же
   папке, где `config.php`) и заполните реальными значениями:
   - `db_driver` → `'mysql'`, данные подключения из шага 2 (таблицы создаются
     автоматически при первом заходе на сайт — вручную запускать
     `sql/schema.sql` не обязательно, он лишь для справки в phpMyAdmin);
   - `admin_password` — пароль для входа в `/admin`;
   - `zadarma_key` / `zadarma_secret` — со страницы **my.zadarma.com →
     Интеграции → Ключи и API**;
   - `zadarma_widget_key` — со страницы **Интеграции → WebRTC**, если нужен
     виджет поддержки на сайте;
   - `airalo_client_id` / `airalo_client_secret` — из личного кабинета
     Airalo Partner API;
   - `payment_instructions` — реальные реквизиты для перевода оплаты;
   - `base_path` — если сайт не в корне домена, а в подпапке (например,
     `/esim`), укажите её здесь.
4. Если base_path не задан пустым, а домен указывает не в корень — задайте
   `base_path` в `config.local.php`, чтобы все ссылки строились верно.
5. Готово — `config.local.php` никогда не попадает в git (см. `.gitignore`),
   поэтому секреты остаются только на сервере.

### Права на запись

PHP-пользователю нужно право записи в:
- `data/` (SQLite-файл, если используется, и кэш токена Airalo);
- `data/uploads/receipts/` (загруженные чеки).

## Безопасность

- `config.local.php`, `includes/`, `data/`, `sql/` закрыты от прямого
  веб-доступа через `.htaccess`.
- Загруженные чеки отдаются только администратору через `admin/receipt.php`
  (проверка сессии), а не напрямую по URL.
- Все формы защищены CSRF-токеном (`csrf_field()` / `csrf_check()`).
- Пароль администратора хранится только в `config.local.php`, вход
  блокируется на 60 секунд после 5 неверных попыток.

## Структура проекта

```
esim-store/
├── config.php                 # значения по умолчанию (без секретов)
├── config.local.example.php   # шаблон — скопировать в config.local.php
├── index.php, destinations.php, destination.php, cart.php, checkout.php, order.php
├── admin/                     # логин, список заказов, выдача чеков
├── includes/                  # bootstrap, db, catalog, zadarma, airalo, orders, auth
├── assets/css/style.css
├── data/                      # sqlite/uploads — не в git
└── sql/schema.sql             # справочная схема для phpMyAdmin
```

## Известные упрощения (что доделать при желании)

- Оплата — только вручную (чек + подтверждение админом), без онлайн-эквайринга.
- Поля каталога Airalo (`includes/airalo.php`) написаны по документации API
  и не проверены на реальном аккаунте — при отличии полей в ответе API
  поправьте функции `airalo_fetch_plans()` / `airalo_create_order()`.
- Один загруженный чек может покрывать сразу несколько тарифов в корзине
  (создаётся по заказу на каждый тариф, все со ссылкой на один файл чека).
