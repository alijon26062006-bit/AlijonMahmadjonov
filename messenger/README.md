# Aloqa — свой мессенджер на своём сервере

- `app/` — приложение: работает в браузере и устанавливается на Android как обычное приложение (PWA).
- `server/` — сервер. Один процесс на Node.js:
  - раздаёт приложение;
  - хранит аккаунты и переписку (SQLite);
  - доставляет сообщения мгновенно (WebSocket);
  - хранит фото, видео и голосовые ограниченное время.
- `index.html` — витрина с макетами экранов.

## Что уже работает

- регистрация по номеру телефона и паролю (тестовый режим, **без SMS-подтверждения**);
- поиск собеседника по номеру и личные чаты;
- сообщения в реальном времени, «печатает…», «в сети / был(а)…», отметки ✓ и ✓✓, разделитель «Непрочитанные»;
- **аудио- и видеозвонки** (WebRTC): входящий звонок с мелодией, камера, микрофон, переключение камеры, история звонков;
- реакции: долгое нажатие — меню с реакциями, двойное нажатие — ❤️;
- ответ, редактирование, пересылка, копирование и удаление сообщений, переход к цитате;
- фото (просмотр на весь экран, зум), видео, файлы, голосовые с настоящего микрофона;
- геопозиция, контакт, опрос, мероприятие;
- оформление: обои (свои из галереи), размытие, затемнение, стеклянный интерфейс, эффект движения при наклоне телефона, цвет темы, размер текста;
- светлая и тёмная тема, жесты как в нативных приложениях;
- автоудаление медиа: через `MEDIA_TTL_HOURS` часов (по умолчанию 72) файлы удаляются с сервера.

**Пока нет:** push-уведомлений при закрытом приложении (звонок дойдёт, только если Aloqa открыта), групп, подтверждения номера по SMS и сквозного шифрования сообщений. Звонки шифруются самим WebRTC, а сообщения защищены только HTTPS: администратор сервера технически может их прочитать.

## Запуск на своём сервере (VPS)

Нужно:
1. Сервер на Linux с установленным Docker.
2. Домен (например, `chat.example.com`), A-запись которого указывает на IP сервера. Подойдёт и бесплатный поддомен, например DuckDNS. Без домена не будет HTTPS, а без HTTPS телефон не даст доступ к микрофону и не позволит установить приложение.

```bash
git clone <этот репозиторий>
cd <репозиторий>/messenger
cat > .env <<EOT
DOMAIN=chat.example.com
TURN_SECRET=$(openssl rand -hex 24)
EOT
docker compose up -d --build
```

Откройте в файрволе сервера порты: `80/tcp`, `443/tcp`, `3478/tcp+udp` и `49160–49200/udp` (для звонков).

Через минуту откройте `https://chat.example.com`. Caddy сам получит бесплатный сертификат Let's Encrypt.

**Установка на Android:** откройте адрес в Chrome, затем «⋮ → Установить приложение» (или «Добавить на главный экран»).

### Настройки (`.env`)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `DOMAIN` | — | ваш домен |
| `MEDIA_TTL_HOURS` | `72` | сколько часов хранить фото, видео и голосовые |
| `MAX_UPLOAD_MB` | `50` | максимальный размер одного файла |
| `TURN_SECRET` | — | секрет TURN-сервера для звонков (любая длинная случайная строка) |

### Резервная копия

Все данные лежат в docker-томе `aloqa-data`: база `aloqa.db` и папка `media/`.

```bash
docker compose exec aloqa sh -c 'cd /data && tar czf - aloqa.db' > aloqa-backup.tar.gz
```

## Запуск без Docker (для разработки)

```bash
cd messenger/server
npm ci
npm start            # http://localhost:8080
```

Требуется Node.js 22.13 или новее (встроенный SQLite).
