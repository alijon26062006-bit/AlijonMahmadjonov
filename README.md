# Alijon Mahmadjonov — личный сайт

Сайт и панель управления к нему. Хостится бесплатно на GitHub Pages,
сервера нет — только статические файлы.

**Сайт:** https://alijon26062006-bit.github.io/alijonmahmadjonov/
**Панель управления:** та же ссылка + `/admin/`

---

## Как всё устроено

Главная мысль: **в HTML нет ни одного текста обо мне**. Всё содержимое лежит
в `data/*.json`, и страница собирается из них в браузере. Поэтому панель
управления может менять сайт, не трогая код.

```
index.html          главная
project.html        страница одного проекта (?slug=имя)
admin/index.html    панель управления

data/profile.json   всё обо мне: тексты, цифры, стек, услуги, контакты
data/timeline.json  мой путь по годам
data/projects.json  проекты
data/diary.json     записи дневника

css/tokens.css      цвета, шрифты, отступы — одно место на весь сайт
css/cosmos.css      космический фон, стекло, градиенты
css/site.css        стили страниц
css/admin.css       стили панели

js/i18n.js          переключатель таджикский / русский
js/render.js        сборка страницы из JSON
js/starfield.js     звёзды на canvas
js/motion.js        появление блоков, меню, кнопка «наверх»
js/admin/           github.js — коммиты, ui.js — поля форм, app.js — экраны

icons/sprite.svg    35 иконок одним файлом
assets/             фото и видео
```

Каждое текстовое поле хранится сразу на двух языках:

```json
{ "tj": "Салом", "ru": "Привет" }
```

## Как добавить проект или запись — через панель

### Первый раз: получить токен (2 минуты, делается один раз)

1. Открой https://github.com/settings/personal-access-tokens/new
2. **Repository access** → `Only select repositories` → выбери `alijonmahmadjonov`
3. **Permissions** → Repository permissions → **Contents** → `Read and write`
4. **Expiration** — 90 дней
5. Нажми *Generate token*, скопируй его целиком

### Дальше

1. Открой `/admin/`, вставь токен, нажми «Войти» — токен запомнится в браузере
2. Правь что нужно: Профиль, Проекты, Мой путь, Дневник, Медиа
3. Нажми **«Опубликовать»** — панель сама сделает коммит
4. Через минуту GitHub Pages обновит сайт

Работает и с телефона.

### Про безопасность честно

Токен хранится в браузере, на странице, которая доступна всем. Поэтому:

- токен выдаётся **только на этот репозиторий** и только на запись файлов;
- если он попадёт к чужому — испортят сайт, но **не тронут аккаунт**;
- срок 90 дней, потом токен сам перестанет работать;
- на странице панели нет ни одного стороннего скрипта — красть токен нечему;
- **не вводи токен на чужом устройстве.** Если ввёл — зайди в Настройки и нажми
  «Выйти», а лучше отзови токен на GitHub.

## Как поменять что-то в коде

Запусти локально — без этого браузер не даст читать JSON-файлы:

```bash
python3 -m http.server 8000
```

Потом открой http://localhost:8000

- **Цвета и шрифты** — `css/tokens.css`, одно место на весь сайт и панель
- **Порядок секций** — `index.html`
- **Как секция рисуется** — `js/render.js`
- **Новое поле в панели** — добавь его в схему в `viewProfile()` в `js/admin/app.js`

## Что важно помнить

- Ветка, из которой публикуется сайт, и ветка, куда пишет панель, должны совпадать.
  Проверить и поменять — в панели, раздел **Настройки**.
- Файл `.nojekyll` нужен, чтобы GitHub Pages отдавал файлы как есть. Не удаляй.
- Форма заказа не отправляет письмо: сервера нет. Она открывает Telegram
  с готовым текстом.
