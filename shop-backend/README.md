# Бэкенд магазина (Python FastAPI + PostgreSQL)

## Что уже работает (шаг 1)
- Регистрация, вход, выход, «кто я» — пароль хранится как хеш argon2, сессия в cookie (HttpOnly).
- Защита от подбора пароля: после 5 ошибок — пауза 10 минут.
- Подключение к поставщику **только на чтение** (денег не тратит):
  - каталог пополнений игр, пакеты и поля формы (Player ID, Zone ID…);
  - цены **с вашей наценкой** (закупочная цена покупателю не показывается, картинки правообладателей не передаются);
  - проверка ID игрока (ник и регион);
  - цены Telegram Stars и Premium.
- Админка: статус ключа и подписки у поставщика, ваш баланс у поставщика, наценка в %.

## Шаг 2: баланс и заказы
- Баланс покупателя ведётся записями (каждое начисление и списание видно в истории).
- Заказ: свежая цена у поставщика → проверка полей → лимиты → списание с баланса и запись заказа
  **одной транзакцией** → заказ у поставщика.
- Защита от двойной траты: строка покупателя блокируется (проверено тестом: 6 одновременных заказов,
  денег на один — проходит ровно один).
- Защита от двойного заказа у поставщика: `Idempotency-Key` = номер нашего заказа.
- Поставщик отклонил заказ → деньги возвращаются сразу. Поставщик вернул заказ позже → возврат один раз.
- Нет ответа от поставщика (таймаут): пополнение игр повторяется тем же ключом (без двойного списания);
  Telegram у поставщика без такой защиты — такой заказ уходит администратору на проверку, а не повторяется.
- Сервер сам проверяет незавершённые заказы каждые 20 секунд.
- Админка: «Стоп продажам», лимиты (на заказ и в сутки), начисление/списание баланса вручную,
  заказы «на проверку», ручной возврат или «выполнено», статистика: выручка, закупка, прибыль.

## Запуск на своём компьютере
```bash
cd shop-backend
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
cp .env.example .env        # заполнить: DATABASE_URL, SECRET_KEY, SUPPLIER_API_KEY, ADMIN_EMAILS
.venv/bin/alembic upgrade head
.venv/bin/uvicorn app.main:app --port 8000
```
Документация API: http://localhost:8000/api/docs

## Тесты
```bash
.venv/bin/python -m pytest -q                       # на SQLite
TEST_DATABASE_URL=postgresql+psycopg://… .venv/bin/python -m pytest -q   # на PostgreSQL
```
Поставщик в тестах подменён: тесты не ходят в интернет и не тратят деньги.

## Безопасность
- Все ключи и пароли — только в `.env` (он в .gitignore).
- Ключ поставщика не пишется в логи и не возвращается в ответах.
