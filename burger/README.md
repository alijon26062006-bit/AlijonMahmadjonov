# The Burger — сайт бургерной

Душанбе, ул. Айни 49 (ориентир GulyaGold). Статический сайт: HTML, CSS и обычный
JavaScript, без сборки и фреймворков.

```
burger/
├── index.html          разметка страницы
├── css/style.css       стили: тёплый чёрный, оливковый и кремовый с логотипа
├── js/menu.js          меню: блюда, состав, вес, цены, доставка
├── js/main.js          меню, корзина-чек, оформление заказа
├── build-single.py     собирает всё в один файл theburger.html
└── assets/
    ├── logo.jpg        логотип (шапка, баннер, подвал)
    └── dishes/         фото блюд
```

## Фото

Оформление построено вокруг фотографий. Пока файла нет, на его месте
остаётся аккуратная заглушка со знаком камеры — вёрстка не ломается.

| Файл | Где видно | Размер |
|------|-----------|--------|
| `assets/hero.jpg` | баннер во весь экран | 16:9, широкое |
| `assets/dishes/<id>.jpg` | карточка блюда и окно блюда | 16:10 |
| `assets/place/hall.jpg` | галерея «Заведение» — зал | 4:3 |
| `assets/place/kitchen.jpg` | галерея — открытая кухня | 4:3 |
| `assets/place/front.jpg` | галерея — вход | 4:3 |
| `assets/place/grill.jpg` | галерея — котлета на гриле | 4:3 |

Имя файла блюда = его `id` из `js/menu.js`: `classic.jpg`, `double-cheese.jpg` и так далее.
