# The Burger — сайт бургерной

Душанбе, ул. Айни 49 (ориентир GulyaGold). Статический сайт: HTML, CSS и обычный
JavaScript, без сборки и фреймворков.

```
burger/
├── index.html          разметка страницы
├── css/style.css       стили: тёплый чёрный, оливковый и кремовый с логотипа
├── js/menu.js          меню: блюда, состав, вес, цены, доставка
├── js/main.js          меню, корзина-чек, оформление заказа
├── build-single.py     собирает всё в один файл theburger.html
└── assets/
    ├── logo.jpg        логотип (шапка, баннер, подвал)
    └── dishes/         фото блюд
```

## Фото — главное на этом сайте

Оформление построено вокруг фотографий: баннер во весь экран и фото на всю карточку.
Нужны два файла помимо блюд:

| файл                | где видно                                  |
|---------------------|--------------------------------------------|
| `assets/hero.jpg`   | баннер во весь экран, горизонтальное 16:9  |
| `assets/place.jpg`  | блок «Заведение», вертикальное 4:5         |

Без них баннер и блок остаются угольными с огнём — пусто не выглядит, но еда не продаёт.

## Фото блюд

Кладём в `assets/dishes/`, имя файла = `id` блюда из `js/menu.js`:

| id в menu.js     | файл                              |
|------------------|-----------------------------------|
| `classic`        | `assets/dishes/classic.jpg`       |
| `double-cheese`  | `assets/dishes/double-cheese.jpg` |
| `set-duo`        | `assets/dishes/set-duo.jpg`       |

Пока файла нет — в карточке рисуется знак заведения, вёрстка не ломается.
Фото горизонтальное, примерно 1200×900, бургер крупно и в кадре целиком.
Фото `classic.jpg` попадает ещё и в круг на баннере, поэтому его выбираем самым удачным.

## Меню и цены

Всё в `js/menu.js`. Одно блюдо:

```js
{
  id: 'bbq-bacon', section: 'burgers', name: 'BBQ Бекон',
  about: 'Котлета, бекон, чеддер, жареный лук, соус барбекю',
  weight: 300,        // граммы
  price: 34,          // сомони
  oldPrice: 39,       // старая цена — зачёркивается, необязательно
  tag: 'hot'          // hit | hot | new, необязательно
}
```

Разделы меню и их порядок — в `SECTIONS` там же. Бургеры и сеты рисуются
крупными карточками с фото, остальные разделы — компактными строками.

Условия доставки — в конце файла:

```js
const DELIVERY = { price: 15, freeFrom: 100, minOrder: 40 };
```

## Как уходит заказ

1. Гость собирает корзину — она оформлена как бумажный чек и сразу считает доставку.
2. Выбирает доставку или самовывоз. Ниже минимальной суммы кнопка не пускает дальше
   и пишет, сколько добавить.
3. В форме указывает имя, телефон, адрес и комментарий.
4. Кнопка открывает Telegram `t.me/theburgertj` с уже готовым текстом заказа —
   гостю остаётся нажать «отправить». Текст заодно копируется в буфер обмена.

Куда уходит заказ и какой телефон в кнопках — первые строки `js/main.js`:

```js
const TG_CHAT = 'theburgertj';
const PHONE_MAIN = '+992939171997';
```

## Один файл для отправки

`python3 build-single.py` собирает `theburger.html` — весь сайт в одном файле
(стили, скрипты и логотип внутри). Открывается двойным кликом без интернета,
удобно показать заказчику или отправить в Telegram. Пересобирать после правок.
