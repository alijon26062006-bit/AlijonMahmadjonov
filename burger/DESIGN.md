# The Burger — дизайн-система

Фактические значения из `css/style.css`. Направление: тёмный гриль-бар, где главное — фотография еды.

## Шрифты

| Роль | Шрифт | Почему |
|------|-------|--------|
| Заголовки | Bebas Neue | Узкие заглавные повторяют слово BURGER на вывеске |
| Текст | Manrope | Спокойный гротеск, хорошо читается в тёмной теме |
| Цифры, чек | IBM Plex Mono | Моноширинные цены и суммы не пляшут в столбце |

Шкала кегля: 12 · 13 · 14 · 16 · 18 · 21 · 26 · 32 · 42 · 56, заголовок баннера
резиновый `clamp(48px, 7.4vw, 96px)`. Цифры в ценах — `tabular-nums`.

## Ритм

Отступы кратны восьми: `--s1` 8 · `--s2` 16 · `--s3` 24 · `--s4` 32 · `--s5` 48 · `--s6` 64 · `--s7` 80.
Секции разделены `--s7`, блоки внутри — `--s3`.

## Движение

Одна кривая на весь сайт: `--ease: cubic-bezier(.16, 1, .3, 1)` — быстрый старт, мягкая остановка.

| Что | Как |
|-----|-----|
| Баннер при загрузке | шесть шагов по 90 мс: подводка → заголовок → текст → кнопки → цифры → бирка |
| Фото баннера | очень медленный наезд, 26 с, туда-обратно |
| Тлеющий свет | дышит 9 с |
| Блоки при прокрутке | подъём 18px, 550 мс, задержка 60 мс на элемент |
| Корзина | выезжает справа, 420 мс |
| Окно заказа | всплывает с масштабом .97 → 1, 380 мс |
| Уведомление | выезжает снизу, 340 мс |
| Нажатие | `scale(.975)` на кнопках, `scale(.96)` на «В заказ» |
| Наведение на карточку | подъём 4px и тень, 350 мс |
| Вкладка раздела | активная сама подъезжает в видимую часть |

Стартовое состояние блоков видимое (`opacity: .62`): если скрипт не сработает,
меню всё равно на месте, а не в пустоте. Плюс страховка — через 3 с всё
проявляется принудительно.

При `prefers-reduced-motion: reduce` гасятся и переходы, и анимации,
а окна открываются мгновенно.

## Телефон

Мобильный вид собран по правилам приложений доставки:

- **Нижняя панель заказа** — появляется, как только что-то добавили: количество, сумма, «Смотреть заказ». Отступ снизу учитывает жест-бар iPhone (`env(safe-area-inset-bottom)`)
- **Корзина — шторка снизу** с ручкой, а не панель сбоку. Смахивается вниз пальцем
- **Окно заказа тоже снизу** — кнопки ближе к большому пальцу
- **Счётчик прямо на карточке**: кнопка «В заказ» превращается в «− 1 +», открывать корзину ради второго бургера не нужно
- **Корзина убрана из шапки** — её работу делает нижняя панель, шапка не переполняется
- **Баннер — полоса 186px**, а не экран на весь рост: заголовок, одна кнопка, и сразу меню (начинается на 285-й точке). Человек пришёл за едой, а не за красивой заставкой
- **Карточки по две в ряд**: фото квадратом, цена плашкой на фото, описание и вес скрыты — на первом экране помещаются четыре блюда
- **Нажатие на блюдо открывает карточку** с фото, составом, весом, калориями и временем приготовления. На телефоне — шторкой снизу, на компьютере — окном по центру. Добавить в заказ можно прямо оттуда
- Вкладки разделов липкие, с прилипанием при прокрутке
- Подъём карточки при наведении только там, где есть мышь (`@media (hover: hover)`), на тач — отклик нажатием
- Прокрутка корзины не «протекает» на страницу (`overscroll-behavior: contain`)

## Проверено перед сдачей

- [x] Все области нажатия ≥ 44×44 px, включая «+» и «−» в чеке
- [x] Контраст текста ≥ 4.5:1 во всех парах
- [x] Фокус с клавиатуры виден, на светлом чеке — своим цветом
- [x] Иконки — SVG, эмодзи в интерфейсе нет
- [x] Заголовки идут по порядку: h1 → h2 → h3 → h4
- [x] Ошибки формы озвучиваются (`role="alert"`), уведомления не забирают фокус
- [x] Телефон проверяется при уходе из поля, а не на каждой букве
- [x] У фото заданы размеры — вёрстка не дёргается при загрузке
- [x] Нет горизонтальной прокрутки на 320, 360, 390, 430, 768, 1024, 1360
- [x] Фокус возвращается на кнопку, из которой открыли корзину
