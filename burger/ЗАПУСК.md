# Запуск сайта

## Шаг 1. Подставить данные клиента

| Что | Где менять |
|-----|-----------|
| Блюда, цены, состав, вес | `js/menu.js`, массив `MENU` |
| Разделы меню | `js/menu.js`, `SECTIONS` |
| Районы и цены доставки | `js/menu.js`, `ZONES` |
| Минимум, бесплатная доставка, время | `js/menu.js`, `DELIVERY` |
| Добавки и что можно убрать | `js/menu.js`, `MODIFIERS` |
| Телефоны, адрес, часы, соцсети | `index.html` — шапка, контакты, подвал |
| Куда уходит заказ | `js/main.js`, `TG_CHAT` и `PHONE_MAIN` |

Фото: `assets/dishes/<id>.jpg` (имя = `id` блюда), `assets/hero.jpg`,
`assets/place/hall.jpg`, `kitchen.jpg`, `front.jpg`, `grill.jpg`.

## Шаг 2. Проверить перед публикацией

- [ ] Все цены совпадают с прайсом заведения
- [ ] Ни одного блюда, которого нет на кухне
- [ ] Телефоны нажимаются и звонят
- [ ] Ссылки Instagram и Telegram открываются
- [ ] Заказ доходит: собрать корзину, оформить, отправить — и проверить,
      что сообщение пришло в рабочий чат
- [ ] Открыть с двух разных телефонов: Android и iPhone

## Шаг 3. Опубликовать

**Вариант А — бесплатно, на GitHub Pages**

1. Влить ветку `claude/phone-store-frontend-design-fzwpi1` в `main`
2. В репозитории: Settings → Pages → Source: Deploy from a branch →
   Branch: `main`, папка `/ (root)` → Save
3. Через пару минут сайт открывается по адресу
   `https://alijon26062006-bit.github.io/AlijonMahmadjonov/burger/`

**Вариант Б — свой домен**

1. Клиент покупает домен (например, `theburger.tj`)
2. В настройках домена: запись CNAME на `alijon26062006-bit.github.io`
3. В репозитории: Settings → Pages → Custom domain → ввести домен → Save
4. Поставить галочку Enforce HTTPS

## Шаг 4. Отдать клиенту

- Ссылку на сайт
- Файл `theburger.html` — весь сайт одним файлом, открывается без интернета
- Договорённость: сколько правок входит в цену и сколько стоит обновление
  меню потом

## Что уже сделано

- Мобильная вёрстка проверена на 320, 360, 375, 390, 393, 414, 430, 768, 1024, 1440
- Контраст текста проходит норму WCAG AA, все нажатия не меньше 44×44
- Работают клавиатура и режим уменьшенной анимации
- Корзина хранится в браузере и переживает перезагрузку
- Заказ проходит целиком: блюдо → корзина → оформление → подтверждение
- Иконка на главный экран телефона, превью для мессенджеров, manifest
