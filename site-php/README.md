# Сайт в одном файле — для хостинга с PHP

`index.php` — это **весь сайт целиком**: разметка, стили, шрифты,
Three.js и весь код внутри одного файла. Плюс приём заявок с формы.

## Как поставить

1. Загрузи `index.php` в `public_html`.
2. Открой сайт в браузере — он уже работает.

Больше ничего загружать не нужно.

## Чтобы заявки приходили в Telegram

Открой `index.php` и заполни две строки в самом верху:

```php
$BOT_TOKEN = '';   // токен от @BotFather
$CHAT_ID   = '';   // твой ID от @userinfobot
```

Пока они пустые, форма работает по-старому: копирует заявку
в буфер и открывает твой чат.

## Что внутри обработчика

- Проверка полей (имя, Telegram, описание) — с понятной ошибкой
- Ловушка для спам-ботов: скрытое поле, которое человек не видит
- Обрезка длины и очистка тегов — чтобы через форму нельзя было
  прислать разметку
- Отправка через cURL, а если он выключен на хостинге — через
  обычный поток

## Как пересобрать после правок

Файл собран из папки `site/`. Правь исходники там, потом собери заново:

```bash
node scripts/build-php.mjs
```

Или правь `site-php/index.php` напрямую — он обычный текстовый файл,
просто большой.
