# Sitora — бот Telegram Stars, Premium и подарков

Отдельный проект (с Donatix не связан): свой бот, своя база, своя служба `sitora` (внутренний порт 8020).
Мини-приложение — по скрытому адресу `https://donatix.tj/_<случайные буквы>/app`: сайт Donatix на него не ссылается,
поисковикам закрыт (noindex). В nginx Donatix добавляется одна строка include (`deploy/nginx-path.sh`, с копией и автооткатом).

- **Бот:** по /start — картинка и кнопка «Открыть магазин»; подарок другу по ссылке `t.me/<бот>?start=g_…`;
  админу — чеки с кнопками «Зачислить / Отклонить», кнопка «⚙️ Админ-панель» (/admin).
- **Админ-панель** (вкладка «Админ» в мини-приложении, только для SITORA_ADMIN_IDS): продажи, чеки с фото,
  заказы в работе (повторить / выполнен / вернуть деньги), цены, карты, поиск клиента, баланс, блокировка.
- **Мини-приложение**: Stars, Premium, подарки; оплата с баланса или переводом
  по реквизитам + чек; заказы; языки ТҶ/RU; чёрно-белый дизайн с анимациями.
- **Поставщик Stars/Premium:** API v2 (`SITORA_FAZER_KEY`, отдельный ключ). Заказ создаётся с Idempotency-Key —
  при обрыве связи повтор не создаст второй заказ; деньги возвращаются только при точном отказе.
- **Подарки:** Bot API `sendGift` с баланса Stars самого бота (пополнить: `/fundgifts 500` в боте).
- **Чеки:** если задан ключ OpenAI — не чек / нет реквизитов / чужие реквизиты отклоняются сразу.

Установка: `sudo bash deploy/install.sh` · обновление: `sudo bash /home/sitora/app/sitora/deploy/update.sh` ·
тесты: `python -m pytest tests -q`.
