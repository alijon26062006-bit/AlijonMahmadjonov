# 🛍️ Витрина — маркетплейс из 4 приложений (Flutter)

Один код — четыре Android-приложения. Ставятся на один телефон рядом друг с другом.

| Приложение | Для кого | Что умеет |
|---|---|---|
| 🛍️ **Витрина** | покупатель | магазины и каталог, поиск, избранное, корзина из нескольких магазинов, промокоды, вход по SMS, оформление, отслеживание заказа |
| 🏪 **Витрина Продавец** | магазин | сводка и выручка за неделю, заказы (принять → собрать → выдать / отклонить), товары (добавить, цена, остаток, снять с продажи), данные магазина, «открыт/закрыт» |
| 🛵 **Витрина Курьер** | курьер | «на линии», доступные заказы, доставка по шагам (забрал → доставил), звонок и маршрут, заработок и история |
| 🛡️ **Витрина Админ** | администратор | оборот и комиссия, «требует внимания», проверка и блокировка магазинов, скрытие товаров, все заказы (отмена, назначение курьера), курьеры, комиссия и тарифы доставки |

Валюта — сомони (`lib/core/format.dart` → `kCurrency`). Вход — по номеру телефона и SMS-коду.

## Демо-режим (пока нет сервера)
Данные хранятся на телефоне, а действия «других участников» приложение изображает само:
продавцу приходят новые заказы, у покупателя заказ сам проходит путь до «Доставлен», курьеру появляются заказы рядом.
SMS не отправляется — код показывается на экране. Выключается в «Настройки → Живой демо-режим».

Демо-номера: продавец «ТехноМир» — `90 000 00 01`, курьер Рустам — `93 000 00 01`, админ — любой номер.

## Сервер (следующий шаг)
Все экраны работают через `MarketStore` (`lib/core/store.dart`). Чтобы подключить общую базу (Supabase),
достаточно переписать его методы на запросы к серверу: модели (`lib/core/models.dart`) уже соответствуют таблицам
`shops`, `products`, `orders`, `couriers`, `settings`.

## Структура
```
lib/
  core/      общее: модели, данные, хранилище, тема, виджеты, вход по SMS
  buyer/     приложение покупателя
  seller/    приложение продавца
  courier/   приложение курьера
  admin/     админ-панель
  main_buyer.dart  main_seller.dart  main_courier.dart  main_admin.dart
```

## Сборка APK
```bash
flutter build apk --release --flavor buyer   -t lib/main_buyer.dart
flutter build apk --release --flavor seller  -t lib/main_seller.dart
flutter build apk --release --flavor courier -t lib/main_courier.dart
flutter build apk --release --flavor admin   -t lib/main_admin.dart
```
GitHub Actions (`.github/workflows/vitrina-apk.yml`) собирает все четыре и выкладывает в Releases.
