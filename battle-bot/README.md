# Битва ников — Telegram-бот

Батлы никнеймов по схеме «канал + бот»: пары публикуются в канале, голосование
идёт внутри бота, итоги подводятся по расписанию.

## Как проходит батл

1. Человек жмёт **🚀 Принять участие** — заявка попадает в очередь.
2. Как только набралась пара, бот **сразу** публикует пост в канал и присылает
   обоим участникам их персональную ссылку для голосующих.
3. Голосовать может любой подписчик канала: один бесплатный голос на матч.
   Счёт виден прямо на кнопках, у лидера — 👑.
4. В час подведения итогов (по умолчанию 18:00 МСК) бот закрывает все матчи
   раунда разом и дописывает результат под постами.
5. **Каждый участник получает личный разбор своего матча**: полная таблица с
   соперниками, их голосами и процентами, своя строка помечена «← вы».
   Победитель и проигравший видят одни и те же цифры — скрывать нечего.
   Если победитель определён жребием, об этом сказано прямо.
6. Следующие раунды идут в тот же вечер по списку `ROUND_TIMES`.

### Лестница

| Раунд | Формат | Кто проходит |
|---|---|---|
| 1 | 1vs1 | победитель пары; кто остался без соперника — проходит без боя |
| 2+ | группы по 4 ника | лучший по голосам |
| Финал | все оставшиеся (до 7) одним матчем | места 1 / 2 / 3 забирают призы |

Исключение ради призов: если в раунде меньше четырёх групп, из каждой проходят
двое — иначе в финале не набралось бы участников на три призовых места.

Сколько раундов получается на практике:

```
16 участников  → 16 → 8 → 4 → чемпион
64 участника   → 64 → 32 → 8 → 4 → чемпион
257 участников → 257 → 129 → 32 → 8 → 4 → чемпион
```

## Что нужно подготовить

* бот от [@BotFather](https://t.me/BotFather) — токен в `BOT_TOKEN`;
* канал, где **бот назначен админом** с правом публикации — его ID в `CHANNEL_ID`
  (вид `-100...`);
* свой Telegram ID в `ADMIN_IDS`.

`BOT_USERNAME` и `CHANNEL_URL` можно оставить пустыми — бот спросит их у Telegram
при запуске. Тогда же он проверит, что видит канал и действительно в нём админ:
если нет — напишет, что именно не так, и не стартует.

Бот работает на long polling — домен и HTTPS не нужны.

## Запуск локально

```bash
cd battle-bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env      # заполнить BOT_TOKEN, CHANNEL_ID, ADMIN_IDS
set -a && source .env && set +a
python bot.py
```

## Запуск на сервере

```bash
git clone <репозиторий> && cd <репозиторий>/battle-bot
bash deploy/install.sh          # от root
```

Скрипт спросит токен, ID канала и ID админа — редактировать файлы руками не
нужно. Он ставит зависимости, заводит системного пользователя `battlebot`,
поднимает службу systemd с автоперезапуском, запускает бота и показывает первые
строки лога: там будет либо `Запущен как @…`, либо конкретная причина отказа.

`.env` кладётся с правами `600` и не попадает в git. Повторный запуск скрипта обновляет код, сохраняя настройки и базу.

### Обновление

Установщик кладёт команду `battle-update`. Она подтягивает код, пересобирает
зависимости и перезапускает бота:

```bash
battle-update
```

`.env` и базу со статистикой обновление не трогает. В конце команда печатает
список подтянутых коммитов и лог запуска.

### Управление

```bash
systemctl status battle-bot
journalctl -u battle-bot -f     # логи в реальном времени
systemctl restart battle-bot
```

## Панель управления

`/panel` — одно сообщение, которое перерисовывается на месте. Доступ только у
`ADMIN_IDS`.

| Раздел | Что можно |
|---|---|
| ⚔️ Батл | открыть приём заявок · подвести итоги сейчас · перенести дедлайн · отменить |
| 🏆 Призы | изменить суммы за 1/2/3 место |
| ⭐ Голоса | цена одного голоса · включить/выключить продажу |
| 📣 Канал | задать главный канал · загрузить фото · опубликовать и закрепить главный пост · удалить посты батла |
| 👥 Люди | найти по нику или ID · карточка · бан · начислить голоса · таблица лидеров |
| 📨 Рассылка | мастер: медиа → текст → кнопки → превью → отправка |
| ⚙️ Настройки | время итогов · лимиты участников · подписка · @username |

### Настройки живут в базе

Всё, что меняет панель, хранится в таблице `settings` и применяется **без
перезапуска бота**. `.env` задаёт только начальные значения при первом
запуске — дальше правит панель.

### Главный пост

Витрина в отдельном главном канале: фото, подпись и кнопка «⚡ Участвую»,
ведущая в бота. Настраивается целиком из панели — ID канала, фото и текст.
Счётчик участников в подписи обновляется сам.

Бот должен быть администратором главного канала с правом публикации.

### Рассылка

Мастер из трёх шагов, каждый можно пропустить:

1. **Медиа** — фото, видео, гифка, файл, аудио, голосовое, кружок или стикер.
2. **Текст** — уходит подписью к медиа, если помещается в 1024 символа;
   иначе отдельным сообщением. Стикер и кружок подпись не несут — текст к ним
   всегда идёт следом.
3. **Кнопки** — сколько угодно, у каждой название и ссылка. Ссылку можно дать
   как `https://t.me/realed`, `t.me/realed` или просто `@realed`.

Перед отправкой бот присылает **превью ровно в том виде**, в каком сообщение
увидят люди, и спрашивает адресата:

| Куда | Что происходит |
|---|---|
| 👥 Всем в личку | рассылка по всем пользователям бота со счётчиком и отчётом |
| 📣 В главный канал | пост выходит в канале-витрине |
| ⚔️ В канал батлов | пост выходит там, где публикуются пары |

Один черновик можно отправить и туда, и туда — заново собирать не нужно.
Посты в каналы запоминаются, поэтому их можно удалить из раздела «Канал».

По ходу рассылки по личкам обновляется счётчик, в конце — отчёт: доставлено,
заблокировали бота, не дошло.

Заблокировавшие бота считаются отдельно: это не сбой, а обычное дело, и
рассылка из-за них не останавливается.

### Если ввели не то

Каждое поле проверяется, и панель объясняет ошибку человеческим языком:

```
Нужно число, а пришло «тысяча». Например: 100.
В «25:00» неверный час: 25. Допустимо 0–23.
Значение №2: Нужно число, а пришло «пятьсот».
```

Экран при этом остаётся на месте — можно просто прислать значение ещё раз.
Всё, что просочилось мимо проверок, ловит общий перехватчик: человек получает
понятный ответ, админу уходит трейсбек, бот продолжает работать.

Сетевые сбои Telegram обрабатываются отдельно. Оборванное соединение —
обычное дело, поэтому запрос автоматически повторяется до трёх раз с
нарастающей паузой; сообщение доходит, а не теряется. Если не помогло, человек
видит «📡 Сеть подвела, повторите», и трейсбек админу не уходит — это не
поломка кода. Одинаковые ошибки отправляются админу не чаще раза в 15 минут,
чтобы один сбой не завалил его десятком писем.

## Жизненный цикл батла

```
набор заявок  →  1 раунд (1vs1)  →  группы по 4  →  финал
      ↑                                                │
      └──────────── новый набор открывается сам ───────┘
```

Батл никогда не заканчивается «в никуда»: как только определился чемпион или
админ отменил батл, бот **сразу открывает набор в следующий** и объявляет об
этом в канале. Участники прошлого батла в новый не переносятся — собираются
новые люди.

Отмена из панели останавливает всё: закрываются все матчи батла, голосовать
в них становится нельзя, участники получают уведомление. Голос проверяет и
статус матча, и статус батла — отменённый батл не примет голос, даже если
отдельный матч почему-то остался открытым.

## Голоса за друзей

Каждый участник получает личную ссылку в меню «🤝 Пригласить друзей». Друг
переходит по ней, **подписывается на канал** и запускает бота — пригласивший
получает голос сверх бесплатного.

Правила намеренно жёсткие, иначе накрутка ломает батл:

* награда выдаётся **один раз за одного приглашённого — навсегда**, это
  гарантирует первичный ключ в базе, а не проверка в коде;
* засчитывается только новый человек: кто уже пользовался ботом, награду не
  приносит;
* сам себя пригласить нельзя;
* без подписки на канал награда ждёт — выдаётся, когда друг подпишется.

Размер награды и включение приглашений — в панели, раздел «🤝 Друзья».
Там же видно, кто приводит больше всех.

## Защита от накрутки

* **обязательная подписка** — проверяется при заявке, при каждом голосе и при
  награде за друга. По умолчанию требуется подписка на **главный канал**: там
  выходит анонс набора. Канал с самими парами в проверку не входит — туда
  заходят по ссылке из поста. Список каналов задаётся в панели
  (⚙️ Настройки → «Каналы подписки»), их может быть несколько — работает как
  спонсорская подписка. Человеку показывается кнопка на каждый неподписанный
  канал и «Я подписался» для повторной проверки;
* один бесплатный голос на матч на аккаунт — гарантируется уникальным индексом
  в БД, поэтому ограничение переживает перезапуск бота;
* **после закрытия раунда голос не примется ничем.** Условия проверяются внутри
  самого запроса записи голоса: матч ещё идёт, дедлайн не прошёл, участник
  действительно в этом матче. Проверять заранее в коде нельзя — между проверкой
  и записью стоит сетевой вызов проверки подписки, за время которого раунд
  успевает закрыться;
* голос за постороннего (подделанная кнопка) не проходит;
* купленный голос, не попавший в матч, возвращается на баланс;
* полный лог голосов (`/votelog`) — можно разобрать спорный финал;
* бан аккаунтов (`/ban`).

Если к дедлайну заявок меньше `MIN_PARTICIPANTS`, батл не стартует: приём
продлевается до следующего слота, уже отданные голоса сохраняются. Иначе приз
в 1000⭐ разыгрывался бы между двумя случайными людьми.

## Дополнительные голоса

Первый голос в матче всегда бесплатный. Дополнительный можно получить двумя
способами, оба живут на одном экране «🎁 Купить голоса»:

**За звёзды.** Человек вводит нужное количество, бот считает сумму по текущей
цене и выставляет счёт. Быстрые кнопки на 1, 5 и 10 голосов — рядом.
Количество ограничено пределом одного счёта Telegram (2500⭐), поэтому при цене
5⭐ максимум — 500 голосов за раз.

**За друзей.** Кнопка «🤝 Или позвать друзей — бесплатно» ведёт на экран
приглашений: подробности выше, в разделе «Голоса за друзей».

Цена голоса, ссылка «звёзды по низкой цене» и включение продажи настраиваются
в панели, раздел «⭐ Голоса».

Повторная доставка апдейта об оплате не начисляет голоса дважды — `charge_id`
уникален в базе. Возврат через `/refund` снимает начисленные голоса, не уводя
баланс в минус.

## Премиум-эмодзи

Тексты в коде остаются обычными — подмена делается на выходе по таблице
`premium_emoji.json` вида «символ → custom_emoji_id».

### Как узнать ID

У Telegram нет поиска ID по картинке: id приходит только вместе с сообщением,
где эмодзи уже стоит. Поэтому сбор встроен в бота — отправьте ему сообщение с
нужными премиум-эмодзи:

| Команда | Что делает |
|---|---|
| `/emojiid` | показать ID эмодзи из сообщения (или из того, на которое отвечаете) |
| `/emojiset` | то же и сразу сохранить в таблицу — **работает без перезапуска** |
| `/emojipreview` | показать все символы разом: видно, что куда встало |
| `/emojimap 🏆 5188344996356448758` | задать ID вручную, когда список ID уже на руках |
| `/emojilist` | что сейчас в таблице |
| `/emojidel 🏆` | убрать символ |

Таблица `premium_emoji.json` лежит в репозитории и уезжает на сервер вместе с
кодом — 21 символ уже заполнен. Без ID остались 🎁 👋 👑 👤: подходящих
премиум-эмодзи для них пока нет, показываются обычные.

Ставить премиум-эмодзи в сообщение может аккаунт с Telegram Premium. Если его
нет — перешлите боту любой пост, где такие эмодзи уже стоят: id придут вместе
с пересылкой.

Таблицу можно заполнять по частям: пустые значения игнорируются, такой символ
остаётся обычным. Файла нет — подмена не включается вовсе.

### Где премиум-эмодзи работают

| Место | Работает | Условие |
|---|---|---|
| Личные сообщения бота | да | Telegram Premium у владельца бота |
| Подписи кнопок | да | одна иконка перед текстом (`icon_custom_emoji_id`) |
| **Посты в канал** | если куплен Fragment-username | бот проверяет это сам, см. ниже |
| Всплывающие уведомления | нет | Telegram рисует их обычным текстом |

Формулировка Bot API: custom emoji доступны ботам, купившим дополнительный
username на [Fragment](https://fragment.com), **либо** в сообщениях, отправленных
ботом в личные чаты, группы и супергруппы, если у владельца бота есть Telegram
Premium. Канала во втором случае в списке нет.

Есть ли у бота Fragment-username, заранее не проверить. Поэтому бот **пробует
сам**: отправляет пост с премиум-эмодзи, и если Telegram отказывает — один раз
повторяет обычными и больше премиум в канал не шлёт. Пост выходит в любом
случае, батл не встаёт. В логе это видно строкой «Telegram не принял
премиум-эмодзи в канале».

| `PREMIUM_EMOJI_IN_CHANNEL` | Поведение |
|---|---|
| `auto` (по умолчанию) | попробовать и отключить при отказе |
| `1` | всегда пробовать, не отключать |
| `0` | никогда не отправлять премиум в канал |

## Цвета кнопок

Bot API даёт кнопкам поле `style` с тремя значениями — `primary` (синий),
`success` (зелёный), `danger` (красный). Без него клиент рисует кнопку своим
обычным цветом. Ограничений нет: работает у любого бота, Premium и Fragment
не нужны.

Как раскрашено в боте:

| Кнопка | Цвет | Почему |
|---|---|---|
| лидер голосования | зелёный | цвет сразу показывает, кто впереди |
| остальные участники | обычный | чтобы зелёный что-то значил |
| Копировать ссылку, Обновить, Пост | синий | служебные, не должны спорить с зелёными |
| Участвовать снова | зелёный | зовём вернуться в игру |
| Подписаться | зелёный | что нужно сделать, чтобы голос засчитался |
| Принять участие в меню | синий | единственное выделенное в нижнем меню |

Красный не используется: в батле нет действий, которые что-то ломают или
отменяют. Он зарезервирован — если появится «Выйти из батла», цвет для неё
уже есть (`keyboards.RED`).

## Структура

```
bot.py                точка входа, polling
config.py             настройки из окружения
core/
  models.py           Player, Slot, Match, статусы
  bracket.py          логика сетки — без Telegram, покрыта тестами
  engine.py           заявки, публикация пар, закрытие раундов, финал
  scheduler.py        дедлайны раундов и фоновая проверка
handlers/
  start.py            /start, deep-links, меню, профиль
  emoji.py            сбор ID премиум-эмодзи
  voting.py           экран голосования, голоса, обновление счёта
  payments.py         Telegram Stars
  admin.py            админка
services/
  channel.py          публикация в канал с учётом лимитов
  subscription.py     проверка подписки
  keyboards.py        клавиатуры
  texts.py            все тексты
  links.py            deep-links и ссылки на посты
  startup.py          проверки настройки при запуске
  emoji.py            подмена на премиум-эмодзи
storage/
  db.py               схема SQLite
  repo.py             все запросы
```

`core/bracket.py` ничего не знает про Telegram — только списки игроков и голоса.
Поэтому вся сетка тестируется без бота и переиспользуется, если позже
понадобится Mini App.
