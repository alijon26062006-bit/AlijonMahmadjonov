# 🛒 ALMAZ TJ — бот-магазин цифровых товаров

Telegram Stars • Telegram Premium • Free Fire (СНГ) • Free Fire (Индонезия) • PUBG Mobile

**Весь интерфейс бота — на таджикском.** Эта инструкция — на русском, для тебя.

---

## Запуск одной командой

```bash
bash start_shop.sh
```

Скрипт сам: создаёт окружение, ставит зависимости, проверяет `.env` и запускает бота.

Чтобы бот работал круглосуточно и переживал перезагрузку сервера:

```bash
bash start_shop.sh --service
```

Логи потом: `journalctl -u almaz-shop -f`

Перед первым запуском нужен `.env`:

```bash
cp .env.shop.example .env && nano .env
```

Свой Telegram ID можно узнать у самого бота — команда `/id`.

### Обновить бота

```bash
bash update_shop.sh
```

Сам встанет на нужную ветку, заберёт свежий код, обновит зависимости и
перезапустит службу. Если в папке есть ваши правки — остановится и скажет,
а не затрёт их.

### Проверить поставщика

```bash
bash check_api.sh                                  # ключ, баланс, сверка SKU
bash check_api.sh --pubg 5123456789                # + ник по ID
bash check_api.sh --ff-cis 123456789 --tg alijon   # можно сразу несколько
```

Показывает сырой ответ API, поэтому видно не только «получилось / нет», но и
что именно вернул поставщик. Заказы не создаются — денег не тратит.

Флаги: `--ff-cis`, `--ff-id`, `--pubg` (ID игрока), `--tg` (username для Stars).

### Если что-то не работает

```bash
bash check_shop.sh
```

Покажет: какой токен в `.env` и какому боту он принадлежит, кого бот считает
админом, запущен ли он, не крутится ли рядом старый бот.

### Добавить админа

```bash
bash add_admin.sh 7418217143
```

Можно несколько сразу, убрать — `bash add_admin.sh --remove <id>`.
Скрипт сам правит `.env`, делает копию `.env.bak` и перезапускает службу.
Последнего админа удалить не даст.

## Что видит покупатель

`/start` → главная панель:

```
⭐️ Telegram Stars ва Premium     ← один вход, внутри выбор Stars / Premium
🔥 Free Fire (ИДМ)
🇮🇩 Free Fire (Индонезия)
🎯 PUBG Mobile
💳 Пур кардани ҳисоб              ← пополнить счёт
🎧 Дастгирӣ      🏆 Беҳтарин харидорон
🧾 Фармоишҳои ман
👍 Шарҳҳо
```

### Покупка

1. Раздел → прайс.
2. Бот просит `@username` (Telegram) или **ID игрока** (игры).
3. **Панель проверки аккаунта** — бот спрашивает FireLoot и показывает ник:
   «✅ Ҳа, аккаунти ман аст» / «🔄 Не, ID-ро иваз мекунам».
   Не удалось проверить — бот честно пишет об этом и просит проверить самому.
4. Итоговый чек: товар, получатель, цена, баланс до и после.
5. Оплата с внутреннего счёта.
6. **Заказ уходит в FireLoot сам**, бот следит за статусом:
   * `completed` → покупателю приходит чек;
   * `failed` / `refunded` / отказ API → **деньги автоматически возвращаются** на счёт,
     покупателю и админу приходит причина;
   * заказ завис → деньги не трогаются, админ получает сигнал проверить руками.

Premium API не поддерживает — эти заказы сразу уходят админу с пометкой «выполнить вручную».

### Пополнение счёта

Сумма (кнопкой или своя) → реквизиты, **4-значный код** для комментария к переводу
и две кнопки оплаты:

* 🏦 **Душанбе Сити** — карта, сумма и код уже подставлены в ссылку;
* 📱 **Alif Mobi** — счёт и сумма подставлены.

Дальше «✅ Пардохт кардам» → чек фото → админ подтверждает → деньги на счету.

## Панель админа

`/admin` или кнопка «🛠 Панели админ».

| Раздел | Что делает |
|---|---|
| 📊 Омор | Пользователи, деньги на счетах, заказы, выручка |
| 🔍 Ҷустуҷӯи корбар | Поиск по **ID** или **@username** |
| 🧾 Фармоишҳои кушода | Заказы в работе → «Иҷро шуд» / «Рад кардан» |
| 💳 Пардохтҳои интизорӣ | Подтверждение пополнений |
| 💲 Нархҳо | Изменить цену, включить/выключить позицию |
| 📢 Эълон ба ҳама | Рассылка |
| 🔌 Таъминкунанда | Режим работы FireLoot |

Команды админа:

* `/balance` — баланс FireLoot (деньги + Stars). **Смотри перед большими продажами.**
* `/sku` — сверяет все SKU каталога с реальным каталогом FireLoot и показывает
  те, которых там нет. Запускается ещё и сама при старте — смотри логи.

В карточке пользователя: баланс, траты, заказы, платежи, кнопки
**➕ пополнить**, **➖ списать**, **🚫 заблокировать**.

Отклонённый заказ всегда возвращает деньги. Каждое движение средств пишется в журнал.

## Цены и товары

Заданы в `shop/catalog.py` — твои реальные цены и SKU FireLoot.

При старте каталог переносится в базу. Дальше:

* **цена и «вкл/выкл»** принадлежат админке — обновление кода их не сбросит;
* **название, SKU, тип, порядок** всегда берутся из `catalog.py`;
* товар, убранный из `catalog.py`, автоматически прячется из меню.

Значит: цены меняй в боте, SKU — в `catalog.py`.


## Цвета кнопок

Telegram даёт кнопкам три цвета, и бот раскрашивает ими **каждую** кнопку
действия. Всё управление — в одном файле `shop/style.py`.

| Цвет | Где |
|---|---|
| 🟢 `success` | пополнить счёт, суммы пополнения, оплатить, «Ҳа, аккаунти ман аст», «Пардохт кардам», у админа — «Иҷро шуд», «Пулро гирифтам», ➕ пополнить, разблокировать |
| 🔵 `primary` | разделы магазина, все товары в прайсе, поддержка, топ клиентов, мои заказы, отзывы, кнопки оплаты Душанбе Сити и Alif, панель админа и все её разделы |
| 🔴 `danger` | отменить, «Рад кардан», ➖ списать, заблокировать, выключенный товар в списке цен |

Серыми намеренно оставлены только «◀️ Бозгашт» и «🏠 Менюи асосӣ» — это
навигация, и на её фоне цветные кнопки действий читаются. Хотите и их
синими — скажите, это одна строка.

В клавиатуре Telegram принимает **только** `danger`, `success` и `primary`.
Значение `link` относится к другому типу сообщений — поставь его на кнопку
клавиатуры, и Telegram отклонит всё сообщение. Это стережёт тест
`test_no_keyboard_button_uses_link_style`, а `test_every_action_button_has_a_color`
следит, чтобы новая кнопка не осталась без цвета.

Цвета появились в **Bot API 10.3**: сервер их принимает всегда, но рисует
приложение — на старом Telegram кнопки будут одинаковыми. Проверить —
команда **`/rang`**. Если сервер вдруг откажет, бот сам снимет заливку и
продолжит работать, а причина уйдёт в лог. Выключить совсем:
`SHOP_BUTTON_COLORS=0`.

## Безопасность

Токен бота и ключ FireLoot лежат **только в `.env`**, который не попадает в git.
В коде их нет. Если ключи когда-то были в открытом файле — смени их:
токен через @BotFather (`/revoke`), ключ — в панели FireLoot.
