## Дальше всё делается командой `bot`

| Команда | Что делает |
|---|---|
| `bot` | обновить код и перезапустить бота |
| `bot log` | смотреть логи (выход — Ctrl+C) |
| `bot stop` / `bot start` | остановить / запустить |
| `bot check` | диагностика: ветка, админы, какой это бот |
| `bot admin 123456789` | сделать человека админом |
| `bot api --pubg 5123456789` | проверить поставщика |
| `bot nick --service` | API проверки ника для других проектов ([описание](NICKAPI_README.md)) |
| `bot donatix` | подключить Donatix: Stars и Premium продаются через него, игры — через FireLoot |
| `bot backup` | собрать архив со всеми данными |
| `bot migrate 1.2.3.4` | переезд на другой сервер |
| `bot force` | обновить, стерев свои правки в коде |

Команда живёт в `/usr/local/bin/bot`, вне репозитория, — поэтому работает
из любой папки и не ломается при обновлениях. Она сама переключает ветку,
доставляет зависимости, перезапускает службу и ждёт, пока бот действительно
свяжется с Telegram. Не дождавшись — покажет причину из журнала.

Если на сервере нет systemd, бот запускается обычным процессом, а логи
пишутся в `data/bot.log` — `bot log` работает одинаково.

## Переезд на другой сервер

На старом сервере одна команда:

```bash
bot migrate 144.31.234.103
```

Порядок в ней такой, чтобы **ничего не потерялось**:

1. проверяет, что переезд возможен (есть `scp`, сервер отвечает) — и только
   после этого трогает бота;
2. **останавливает бота** — с этой секунды база не меняется;
3. снимает свежую копию всех данных;
4. передаёт её на новый сервер;
5. сверяет контрольную сумму — файл должен доехать байт в байт;
6. печатает готовую команду для нового сервера.

Почему остановка идёт до копии: пока бот работает, покупатели пополняют
счета и покупают. Копия, снятая заранее, этих денег уже не содержит.

Если что-то сорвётся, бот **сам возвращается в работу**. Если запустить его
не удалось — скажет об этом прямо, а не промолчит.

На новом сервере выполняется команда, которую напечатал `bot migrate`:

```bash
cd ~ && git clone -b <ветка> <репозиторий> AlijonMahmadjonov && \
cd AlijonMahmadjonov && bash restore_bot.sh ~/almaz-backup-….tar.gz
```

Старый сервер остаётся нетронутым: не получилось — `bot start`, и он снова
работает. Архив удалите с обоих серверов после переезда: внутри токен и ключ
поставщика.

Просто копию, без переезда, можно снять в любой момент: `bot backup`.

### Покупка

1. Раздел → прайс.
2. Бот просит `@username` (Telegram) или **ID игрока** (игры).
3. **Панель проверки аккаунта** — бот спрашивает FireLoot и показывает ник:
   «✅ Ҳа, аккаунти ман аст» / «🔄 Не, ID-ро иваз мекунам».
   Не удалось проверить — бот честно пишет об этом и просит проверить самому.
4. Итоговый чек: товар, получатель, цена, баланс до и после.
5. Оплата с внутреннего счёта.
6. **Заказ уходит в FireLoot сам**, бот следит за статусом:
   * `completed` → покупателю приходит чек;
   * `failed` / `refunded` / отказ API → **деньги автоматически возвращаются** на счёт,
     покупателю и админу приходит причина;
   * заказ завис → деньги не трогаются, админ получает сигнал проверить руками.

Premium API не поддерживает — эти заказы сразу уходят админу с пометкой «выполнить вручную».

### Пополнение счёта

Сумма (кнопкой или своя) → реквизиты, **4-значный код** для комментария к переводу
и две кнопки оплаты:

* 🏦 **Душанбе Сити** — карта, сумма и код уже подставлены в ссылку;
* 📱 **Alif Mobi** — счёт и сумма подставлены.

Дальше «✅ Пардохт кардам» → чек фото → админ подтверждает → деньги на счету.

## Подкатегории

Free Fire открывается в два шага: сначала **💎 Алмосҳо** или **🎟 Ваучерҳо**,
потом прайс. У Free Fire Индонезия — алмазы и Membership. У PUBG и Stars
подкатегория одна, поэтому прайс открывается сразу.

Каждый товар занимает **всю строку** — видно и название, и цену целиком.
Внизу «◀️ Бозгашт» возвращает к выбору подкатегории.

Названия подкатегорий меняются в `/admin` → ⚙️ **Танзимот** → 🗂 **Номи
зербахшҳо**. Обновление кода их не сбрасывает.

## Раздел «Дигар бозиҳо»

После PUBG в меню появляется 🎮 **Дигар бозиҳо**. Внутри — Mobile Legends
(глобал и СНГ), Honor of Kings, Blood Strike, Marvel Rivals. У PUBG добавились
Prime и Elite Pass.

**Все новые игры выключены**, пока вы не проверите цены: стартовые цены
посчитаны как закупка × 11.5, и ваш реальный курс может отличаться.
Пока раздел пуст, кнопка в меню вообще не показывается.

Как включить: `/admin` → 💲 **Нархҳо** → 🎮 **Дигар бозиҳо** → игра. Экран
покажет, сколько товаров и сколько из них убыточных, даст посмотреть цены
по одному и включить всю игру одной кнопкой.

### Добавить игру, которой ещё нет

`/admin` → 💲 **Нархҳо** → ➕ **Бозии нав аз таъминкунанда**.

Бот заберёт каталог поставщика, покажет игры, которых в боте ещё нет, и по
нажатию заведёт все их товары: SKU, закупочную цену и цену продажи. Править
код не нужно.

Цена считается как **закупка × курс + процент**. Процент задаётся в
⚙️ **Танзимот** → 📈 **Фоизи нарх** (по умолчанию 20%), курс — там же рядом.

Новые товары приходят выключенными: проверьте цены, потом включите игру.
Добавленные из панели игры переживают обновление кода — сброс их не касается.

Если в игре включена ровно одна подкатегория, лишнего экрана покупатель не
увидит — сразу прайс.

### Mobile Legends: ID и сервер

Mobile Legends требует не только ID, но и номер сервера. Бот просит их одной
строкой — `123456789 1234` — принимает и вид `123456789(1234)`, разбирает и
передаёт поставщику отдельным полем.

## Реквизиты оплаты

`/admin` → ⚙️ **Танзимот** → 💳 **Реквизитҳо**.

Два способа встроены с самого начала, ссылки для них уже готовы:

* **🏦 Душанбе Сити** — меняются номер карты и имя владельца
* **📱 Alif Mobi** — меняется номер счёта

Ссылки оплаты бот собирает сам: карта, сумма и код подтверждения
подставляются автоматически. Любой способ можно выключить — он пропадёт и
из текста, и из кнопок. Последний включённый выключить нельзя, иначе
покупатели не смогли бы платить.

Значения берутся из `.env` только при первом запуске, дальше живут в базе —
обновление кода их не сбросит.

## Обязательная подписка на каналы

`/admin` → ⚙️ **Танзимот** → 📢 **Каналҳои обуна**. Каналов можно добавить
сколько угодно. Пока человек не подписан на **все**, бот ему не отвечает —
показывает список со ссылками и кнопку «Обуна шудам — санҷед».

**Бот должен быть админом в каждом канале** — иначе он не может проверить
подписку. При добавлении бот сам это проверяет и скажет, если не получилось.

Если позже бота из канала удалят, покупатели не окажутся заперты: канал,
который не удаётся проверить, считается пройденным.

## Отзывы

`/admin` → ⚙️ **Танзимот** → 💬 **Канали шарҳҳо** — указать канал.

После каждой выполненной покупки бот сам предлагает написать отзыв. Текст
уходит вам с кнопками **✅ Нашр кардан** / **❌ Рад кардан**. При одобрении
отзыв публикуется в канал, автору приходит уведомление.

## Рассылка в три шага

`/admin` → 📢 **Эълон ба ҳама**:

1. фото или видео (или `-`, чтобы пропустить);
2. само сообщение — текст, голосовое, стикер, кружок, документ, файл, ссылка;
3. кнопки-ссылки: `Название | https://ссылка`, по одной в строке (или `-`).

Потом показывается сводка и число получателей, и только после подтверждения
рассылка уходит. Сообщения копируются как есть, поэтому работает любой формат.

## Партнёрские цены

Для друзей и коллег можно поставить свои цены — ниже обычных.

**Как добавить партнёра.** `/admin` → 🤝 **Шарикон** → ➕ **Шарики нав** →
написать его ID или `@username`. Человек должен хоть раз нажать `/start`,
иначе бот его не знает. Ему сразу придёт уведомление, что он стал партнёром.

**Как поставить цену.** `/admin` → 💲 **Нархҳо** → раздел → товар. У каждого
товара теперь две цены:

* **💲 Нархи оддӣ** — для всех
* **🤝 Нархи шарикӣ** — только для партнёров

Цена задаётся отдельно на каждый товар. Ввести `0` — партнёрская цена
снимается, и партнёр платит обычную. Цену выше обычной бот не примет —
это была бы ошибка.

**Что видит партнёр.** Ничего делать не нужно: нажал `/start` — и везде уже
его цены. В приветствии и в каждом разделе появляется пометка
«🤝 Нархи шарикӣ барои шумо фаъол аст». Списывается с баланса ровно
партнёрская цена.

Стартовые партнёрские цены для Free Fire СНГ и PUBG уже заполнены — те же,
что были в вашем прежнем боте. Любую можно изменить из панели. У Free Fire
Индонезия, Stars и Premium партнёрской цены нет: поставьте, если нужна.

## Цены и товары

Заданы в `shop/catalog.py` — твои реальные цены и SKU FireLoot.

При старте каталог переносится в базу. Дальше:

* **цена и «вкл/выкл»** принадлежат админке — обновление кода их не сбросит;
* **название, SKU, тип, порядок** всегда берутся из `catalog.py`;
* товар, убранный из `catalog.py`, автоматически прячется из меню.

Значит: цены меняй в боте, SKU — в `catalog.py`.

## Цвета кнопок

Telegram даёт кнопкам три цвета, и бот раскрашивает ими **каждую** кнопку
действия. Всё управление — в одном файле `shop/style.py`.

| Цвет | Где |
|---|---|
| 🟢 `success` | пополнить счёт, суммы пополнения, оплатить, «Ҳа, аккаунти ман аст», «Пардохт кардам», у админа — «Иҷро шуд», «Пулро гирифтам», ➕ пополнить, разблокировать |
| 🔵 `primary` | разделы магазина, все товары в прайсе, поддержка, топ клиентов, мои заказы, отзывы, кнопки оплаты Душанбе Сити и Alif, панель админа и все её разделы |
| 🔴 `danger` | отменить, «Рад кардан», ➖ списать, заблокировать, выключенный товар в списке цен |

Серыми намеренно оставлены только «◀️ Бозгашт» и «🏠 Менюи асосӣ» — это
навигация, и на её фоне цветные кнопки действий читаются. Хотите и их
синими — скажите, это одна строка.

В клавиатуре Telegram принимает **только** `danger`, `success` и `primary`.
Значение `link` относится к другому типу сообщений — поставь его на кнопку
клавиатуры, и Telegram отклонит всё сообщение. Это стережёт тест
`test_no_keyboard_button_uses_link_style`, а `test_every_action_button_has_a_color`
следит, чтобы новая кнопка не осталась без цвета.

Цвета появились в **Bot API 10.3**: сервер их принимает всегда, но рисует
приложение — на старом Telegram кнопки будут одинаковыми. Проверить —
команда **`/rang`**. Если сервер вдруг откажет, бот сам снимет заливку и
продолжит работать, а причина уйдёт в лог. Выключить совсем:
`SHOP_BUTTON_COLORS=0`.

## Безопасность

Токен бота и ключ FireLoot лежат **только в `.env`**, который не попадает в git.
В коде их нет. Если ключи когда-то были в открытом файле — смени их:
токен через @BotFather (`/revoke`), ключ — в панели FireLoot.
