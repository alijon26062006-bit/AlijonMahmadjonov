# 🛒 Бот-магазин цифровых товаров

Telegram Stars • Telegram Premium • Free Fire (СНГ) • Free Fire (Индонезия) • PUBG Mobile

**Весь интерфейс бота — на таджикском языке.** Эта инструкция — на русском, для тебя.

---

## Запуск за 3 минуты

```bash
pip install -r requirements.txt          # aiogram и остальное
cp .env.shop.example .env                # скопировать настройки
nano .env                                # вписать токен и свой ID
python -m shop.main                      # запустить
```

Свой Telegram ID можно узнать прямо у бота: команда `/id`.

`/start` → главная панель (как на присланном скриншоте):

```
🔥 Free Fire (ИДМ)
🇮🇩 Free Fire (Индонезия)
🎯 PUBG Mobile
💳 Пур кардани ҳисоб              ← пополнить счёт
🎧 Дастгирӣ      🏆 Беҳтарин харидорон
🧾 Фармоишҳои ман
👍 Шарҳҳо                         ← ссылка на канал отзывов
```

Зачёркнутые на скриншоте кнопки (Профиль, Калькулятор, Информация) не делались — как ты и просил.

### Как проходит покупка

1. Покупатель выбирает раздел.
2. **Telegram** → второй шаг: `Stars` или `Premium` (3 / 6 / 12 месяцев).
3. **Игры** → сразу прайс: алмазы, UC, подписки.
4. Бот просит `@username` (для Telegram) или **ID игрока** (для игр).
5. **Панель проверки ID** — бот показывает ID и ник, покупатель подтверждает:
   «✅ Ҳа, аккаунти ман аст» / «🔄 Не, ID-ро иваз мекунам».
6. Итоговый чек: товар, получатель, цена, баланс до и после.
7. Оплата с внутреннего счёта. Денег не хватает → кнопка пополнения.
8. Заказ уходит админу, покупателю приходит `#номер`.

### Пополнение счёта

Сумма (готовые кнопки или своя) → бот выдаёт реквизиты Душанбе Сити,
**4-значный код** для комментария к переводу и кнопку
«🔗 Кушодани Душанбе Сити» с уже подставленными картой, суммой и кодом.
Дальше «✅ Пардохт кардам» → можно приложить чек → админ подтверждает → деньги на счету.

> Кнопка ссылки появляется, только когда заполнен `SHOP_PAY_LINK`.
> Пришлёшь шаблон — впишем одну строку в `.env`, менять код не нужно.

## Панель админа

Команда `/admin` или кнопка «🛠 Панели админ» в главном меню.

| Раздел | Что делает |
|---|---|
| 📊 Омор | Пользователи, деньги на счетах, заказы, выручка |
| 🔍 Ҷустуҷӯи корбар | Поиск по **ID** или **@username** |
| 🧾 Фармоишҳои кушода | Открытые заказы → «Иҷро шуд» / «Рад кардан» |
| 💳 Пардохтҳои интизорӣ | Подтверждение пополнений |
| 💲 Нархҳо | Изменить цену любого товара, включить/выключить позицию |
| 📢 Эълон ба ҳама | Рассылка всем пользователям |

В карточке пользователя: баланс, сколько потратил, сколько заказов, последние
заказы и платежи, кнопки **➕ пополнить вручную**, **➖ списать**, **🚫 заблокировать**.

Отклонённый заказ **автоматически возвращает деньги** покупателю.
Каждое движение денег пишется в журнал `balance_log`.

## Структура

```
shop/
  config.py       настройки из .env
  catalog.py      товары и стартовые цены
  db.py           SQLite: счета, заказы, платежи, журнал
  texts.py        ВСЕ тексты бота (таджикский) — правки здесь
  keyboards.py    кнопки и раскладка меню
  payments.py     код подтверждения и ссылка Душанбе Сити
  supplier.py     подключение API поставщика
  middlewares.py  блокировка, защита от падений
  handlers/       menu · purchase · topup · admin
  main.py         запуск
```

Цены заданы в `catalog.py`, но при первом запуске переносятся в базу —
дальше меняются прямо из панели админа и при обновлении кода не сбрасываются.

## Подключение API поставщика

Всё подготовлено заранее — в `shop/supplier.py`:

```python
class HttpSupplier:
    _CHECK_PATH = "/check"     # проверка ID игрока → ник
    _ORDER_PATH = "/order"     # оформление заказа
```

Когда пришлёшь документацию и ключ:

1. В `.env`: `SHOP_SUPPLIER=http`, `SHOP_SUPPLIER_URL=...`, `SHOP_SUPPLIER_KEY=...`
2. Поправим два пути и разбор ответа под формат поставщика.

Остальное уже работает: ник автоматически подставится в панель проверки ID,
номер заказа поставщика сохранится в `orders.external_id`.
Пока `SHOP_SUPPLIER=manual` — заказы выполняет админ вручную, бот полностью рабочий.

## Важно про цвета кнопок

На скриншоте кнопки разноцветные — это **тема оформления Telegram у покупателя**,
а не настройка бота. Bot API не позволяет задать цвет кнопки: в клиенте все
inline-кнопки красятся одним цветом темы. Поэтому разделы различаются иконками,
порядком и группировкой — раскладка повторяет присланный скриншот один в один.
