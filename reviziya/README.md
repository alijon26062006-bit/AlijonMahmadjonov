# Ревизия: сканер ценников

Страница для подсчёта товара на ревизии. Камера включена всё время: сотрудник подносит
бирку в рамку, сканер сам её снимает, Claude читает цену, и она прибавляется к сумме.

Сейчас это режим проверки на одном телефоне.

## Как пользоваться

1. Открыть `reviziya/` на телефоне по HTTPS (камера работает только по HTTPS).
2. Вкладка «Настройки»: вставить ключ Anthropic и нажать «Сохранить и проверить».
3. Вкладка «Сканер»: «Включить камеру» и подносить бирки в рамку.

## Как это устроено

- `index.html` — экран и оформление.
- `app.js` — камера, автоснимок, запрос в Claude, счёт.
- `vendor/anthropic-sdk.js` — официальная библиотека `@anthropic-ai/sdk` 1.14.0, собранная в один файл для браузера.

Автоснимок: область рамки несколько раз в секунду сжимается в маленькую серую картинку.
Когда соседние картинки почти не отличаются, бирка считается неподвижной и уходит один кадр.
После этого сканер ждёт, пока картинка сильно изменится (бирку убрали), и только тогда
готов снимать следующую. Так одна бирка не считается дважды.

Фото не сохраняются. В телефоне остаются только цифра, время и сколько секунд читался ценник.

`?debug=1` в адресе показывает числа детектора на экране, чтобы подстроить пороги на настоящем телефоне.

## Ограничения режима проверки

- Ключ Anthropic лежит в браузере телефона и уходит прямо в Anthropic. Сотрудникам так давать нельзя:
  для них ключ должен жить на сервере.
- Счёт хранится в одном телефоне. Общей суммы по всем сотрудникам и админ-панели пока нет.
- Проверено на искусственной камере с подставным ответом вместо Claude. На настоящем телефоне
  с настоящим ключом ещё не проверялось.
