# Кабинет продавца

Веб-приложение для магазинов и ресторанов, которые продают через сервис доставки:
товары, заказы, продажи в магазине, расходы, статистика и подключение к оплате Alif.

## Запуск

Сборка не нужна — это обычные ES-модули. Их нельзя открыть двойным кликом по файлу
(браузер не грузит модули с `file://`), поэтому нужен любой локальный сервер:

```bash
npm start            # или: python3 -m http.server 8080
```

и открыть http://localhost:8080.

Проверка синтаксиса всех модулей:

```bash
npm run check
```

## Структура

```
index.html               разметка-оболочка
css/app.css              стили; цвета — токены в :root, тёмная тема переопределяет только их
js/
  app.js                 точка входа: render(), навигация, обработчики событий
  config.js              справочники и константы (комиссия, единицы, статусы)
  state.js               состояние магазина (S), setS(), save(), состояние интерфейса
  lib/format.js          форматирование денег, дат, телефона, склонения
  services/storage.js    localStorage: данные магазина и вход
  data/demo.js           пример магазина, миграция старых данных
  domain/orders.js       суммы и комиссия заказа, списание остатков
  domain/analytics.js    выручка, прибыль, продажи по товарам, готовность к запуску
  ui/dom.js              иконки, боковая панель, уведомления, ошибки форм
  views/                 экраны: onboarding, home, orders, catalog, stats,
                         expenses, finance, storefront, shop
```

Правила:

- Каждый экран — функция `vИмя()`, возвращающая HTML-строку; `render()` в `app.js` выбирает экран.
- Весь пользовательский текст проходит через `esc()` перед вставкой в HTML.
- Состояние меняется только через `S` из `state.js`, затем вызывается `save()` и `render()`.
  Целиком состояние заменяет только `setS()`.

## Что сейчас работает в тестовом режиме

- Данные хранятся в браузере (`localStorage`). Общая база для всех продавцов — следующий шаг.
- SMS-код при входе показывается на экране, SMS не отправляется.
- Онлайн-оплата не подключена. Расчёт комиссии (20%) и экран «Деньги» готовы под
  маркетплейс-платежи Alif: оплата замораживается до получения заказа, затем Alif
  переводит долю продавца на его терминал.
