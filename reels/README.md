# Python с нуля — видео-уроки для Reels / Shorts / TikTok

Вертикальные видео 1080×1920 с озвучкой, субтитрами, печатью кода со звуком
клавиш, звуковыми эффектами, фоновой музыкой и жёлтым человечком за ноутбуком.

## Как собрать урок

```bash
sudo apt install ffmpeg rhvoice rhvoice-russian
pip install numpy pillow

python3 reels/lessons/lesson01_print.py                 # видео -> reels/out/
python3 reels/lessons/lesson01_print.py preview 5 60    # кадры на 5-й и 60-й секунде
```

На выходе два файла: `urokNN_*.mp4` (голос + звуки + музыка) и
`urokNN_*_bez_muzyki.mp4` (голос + звуки, чтобы наложить свою музыку).

## Как написать новый урок

Скопируй `lessons/lesson01_print.py` и поменяй список `beats`. Каждый бит:

- `say` — что говорит диктор (английские слова пиши по-русски: «принт», «Пайтон»);
- `sub` — субтитры (`так` выделяется жёлтым), если не указаны — берётся `say`;
- `do` — что на экране:
  - `Title(верх, крупно, низ)` — заставка;
  - `Card(заголовок)` + `Bullet(текст)` — карточка с пунктами;
  - `Syntax(код, части)` + `Hl(i)` — разбор строки кода по частям;
  - `Term()` + `Type(строки...)` + `Run(вывод..., error=False)` — терминал.

Длительность подстраивается под озвучку автоматически.
