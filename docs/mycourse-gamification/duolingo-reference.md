# Референс: экраны Duolingo (скриншоты владельца, 14.11.2026)

Владелец прислал 6 скриншотов Duolingo как ориентир по ощущению и механикам.
Копировать нельзя: ни сову, ни их иллюстрации, ни их тексты. Берём только
устройство экранов и переносим на свой стиль (Пайко, тёмная тема mycourse.tj,
зелёный акцент). Сами скриншоты в репозиторий не кладём.

## Что на экранах

1. **Знакомство с маскотом.** Тёмный фон, маскот по центру на тени-подставке,
   облачко-реплика сверху («Привет! Я Duo!»), одна большая кнопка «Далее» внизу.
   Ничего лишнего на экране.
2. **Обещание короткого онбординга.** Та же композиция, реплика: «Ответьте на
   7 коротких вопросов — и начнём первый урок!». Жирным выделено число.
3. **Зажечь серию.** Тёмный экран, погасшее пламя с маленьким светящимся ядром
   и мягким свечением вокруг. Текст: «Смахните вверх, чтобы разжечь пламя
   ударного режима!» — серию «зажигает» сам пользователь жестом.
4. **Анимация зажигания.** Пламя загорается, маскот рядом с ним, вокруг лопаются
   белые «пузыри», печатается реплика по буквам.
5. **Итог серии.** Огромная оранжевая цифра «1», подпись «день в ударе»,
   реплика «Сможете заниматься каждый день?», внизу 7 кружков недели
   (Сб … Пт), сегодняшний — с галочкой.
6. **Путь курса.** Верхняя панель: флаг курса, серия (огонёк 0), кристаллы 543,
   энергия 25. Синяя плашка раздела («Модуль 2, раздел 1 · Покупай продукты»)
   с кнопкой справочника. Ниже вертикальный змейкой путь из круглых
   «таблеток»-узлов с иконками типа занятия: видео, книга (теория), звезда,
   гантель (тренировка). Над текущим узлом — облачко «Перейти сюда?».
   Закрытые узлы серые. Сбоку — тёмные силуэты персонажей и костёр с тремя
   звёздами (награда за раздел).

## Что берём в Py·Достон (по дорожной карте, в свой этап)

| Приём Duolingo | Наш вариант | Этап |
| --- | --- | --- |
| Маскот + облачко + одна кнопка | Пайко говорит на таджикском, одна кнопка | 3 |
| «7 вопросов — и первый урок» | Короткий онбординг: цель недели (2–5 дней), мечта (бот/сайт/игра/AI) | 3–4 |
| Жест «зажги пламя» | Ученик сам зажигает **Гулхан** при выборе недельной цели | 4 |
| Огромная цифра + кружки недели | Итог урока: «+40 XP», кружки дней **недели** с целью, а не ежедневное давление | 4 |
| Путь из круглых узлов с иконками типа | Карта шагов урока: видео / теория / амалия / ДЗ / экзамен; уже есть шаги «4/4» | 3 |
| Плашка раздела сверху | Плашка блока: «Блок 2 · Функсияҳо» | 3 |
| Верхняя панель ресурсов | XP, уровень, тенге, Гулхан — только данные с сервера | 3 |
| Костёр со звёздами в конце раздела | Награда за блок (значок «Фотеҳи блок») | 3 |

## Чего не берём

- Энергию/«сердечки», ограничивающие учёбу.
- Тексты и уведомления, давящие на ежедневную серию («потеряешь всё»).
- Платные ускорения и что-либо за реальные деньги.
