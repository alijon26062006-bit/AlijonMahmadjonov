Охота на баги

Шикори Баг
for i in range(len(items)):
    total += items[i+1] # ← баг 1/3
print("Итого: " + total) # ← ?
Турнир по исправлению ошибок: код с несколькими спрятанными багами, 15 минут. Баги — из Бестиария, так что турнир учит читать ошибки. Каждую пятницу; есть отдельная сетка для новичков.
Новичкам: даже 1 найденный баг даёт очки — нет «нуля».

Парный режим в браузерном редакторе: роли меняются каждые 5 минут, XP получают оба. «Приведи друга» награждает, когда друг завершит Блок 0, а не просто зарегистрируется — так нет спама приглашениями.
Новичкам: учиться в паре с другом проще, чем одному.

Новичкам: объяснять то, что понял вчера, — лучший способ закрепить.
