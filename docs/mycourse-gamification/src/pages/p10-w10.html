Қуллаи Сомонӣ

содержание блока — идея
Пик Исмоила Сомони · горная экспедиция

Высочайшая вершина Таджикистана — символ финального проекта. Каждая контрольная точка проекта — лагерь на новой высоте. Альтиметр в профиле показывает, как высоко поднялся ученик, а команда друзей идёт в одной связке.

Связка
Команда из 2–3 учеников (по желанию). Ревью кода напарника даёт «кислород» — бонус всей связке.
Погода
Неожиданный челлендж: «заказчик» добавил требование. Как в реальной работе — но с подсказками.
Лагерь = проверка
Переход в новый лагерь — только после проверки чек-пойнта наставником или автотестами.
Дневник экспедиции
Короткие записи о решениях — готовый текст для README и рассказа на собеседовании.
Финальное испытание «Демо-рӯз» (Демо-день)
Публичная защита: видео-демо, живая ссылка на продукт и репозиторий. Оценка наставника и peer-review по прозрачной рубрике: работает ли, понятен ли код, есть ли тесты, как решены проблемы.
