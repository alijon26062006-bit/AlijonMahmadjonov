Игровой слой «слушает» курс и не доверяет браузеру

Подходит к любому бэкенду. Пример стека: Python (Django или FastAPI) + PostgreSQL + Redis + WebSocket/SSE.

Внешние проверки
Telegram Bot API · GitHub API · AI-сервис
Шина событий
таблица events или Redis Streams · уникальный idem_key
Валидатор
проверка подлинности, дубликатов, лимитов, аномалий
Движок правил
правила XP, квестов, значков как данные (JSON/YAML) — меняются без релиза
Журнал (append-only)
xp_ledger · wallet_tx — каждую монету можно объяснить и откатить
Прогресс
квесты, серии, значки, бестиарий, радар
Проекции
профиль, уровень, лиги (Redis sorted sets), рейтинги
Уведомления
WebSocket/SSE → анимация в браузере · Telegram · e-mail раз в неделю
Планировщик (cron / Celery)
00:00 — миссии дня по часовым поясам · вс 23:59 — итоги Гулхана и лиг · эхо-миссии по расписанию
