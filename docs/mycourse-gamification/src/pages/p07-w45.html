Блок 4 · Объектно-ориентированное программирование
Заводи Роботҳо
Завод роботов
конструктор + арена
Сюжет
Завод, где по чертежам (классам) собираются роботы (объекты). Ученик проектирует собственную линейку роботов, а в финале выводит их на арену против Мегабота.

Блок 5 · Базы данных
Парвандаи Тиллои Помир
Дело о памирском золоте
детектив
Сюжет
Из хранилища исчез караван с памирским золотом. Все улики — в базе данных. Ученик — детектив агентства «SELECT»: каждый урок открывает новые улики, а запросы раскрывают историю.
Уроки курса → игровые квесты
SQL«Первые улики» — SELECT / WHERE / ORDER BY по таблице свидетелей SQLite«Своя картотека» — создать базу дела из Python Бот с базой данных«Бот-информатор» — бот принимает донесения и сохраняет их в БД PostgreSQL и Docker«Штаб-квартира» — перенос дела в «большой сейф» в контейнере PostgreSQL на сервере«Сеть агентов» — база доступна онлайн, бот работает с ней
